# 胜率研究第一版特征与评测口径

本文件固定离线研究的输入边界。它不改变产品当前推荐、战绩或局内参考的含义，不声明任何模型已具备国服校准能力。

## 第一版样本

| 字段 | 含义与要求 |
| --- | --- |
| `game` | 来源范围内的对局分组键；公开源ID经哈希处理后使用，同场所有快照必须使用同一个键 |
| `patch` | 数据明确提供的补丁，格式主版本.次版本；不能用下载日期推断 |
| `region` | 数据直接记录或公开对局ID前缀可证明的地区；不得将EUW1等映射成国服 |
| `queue` | 明确queue ID；只有CLASSIC时为null，不写420 |
| `createdAt` | 明确游戏开始时间；缺少时为null，不用match ID或CSV顺序充当时间 |
| `label` | 蓝方最终胜负0/1；原始双方结果必须互补，冲突拒绝 |
| `blue` / `red` | 双方各5个唯一英雄ID，合计10位；不完整、重复或未知英雄拒绝 |
| `time` | 局内快照时刻，秒；赛前样本不使用过程数据 |

下载目录仅为 `.local/win-probability/source/`。准备后的公开研究样本仍在忽略目录，报告不含玩家名、PUUID、SummonerFk、原始对局ID。应用个人战绩不会被此工具读取。

## 可运行的赛前基线

每个英雄一维，蓝方选中记+1，红方选中记−1，未选中记0。英雄词表仅作为固定编码，不从测试标签计算英雄强度。模型是L2逻辑回归，只在训练集拟合均值、标准差、系数和截距。

该基线使用英雄集合，不假定来源B1至B5的次序就是上野中下辅。它没有玩家历史、段位、对位、协同和角色特征，不把结算KDA、金币、塔、伤害当赛前特征，也不把当前项目的规则分视为胜率。

## 综合赛前模型的后续输入条件

玩家历史需要能够证明“历史结束早于目标对局开局”，并限定同队列、最近20场、有效胜负。预期指标包括英雄与分路经验、收缩后的历史胜率、平均KDA、分均伤害/补刀/金币/视野/治疗及样本覆盖。

未知指标须有缺失标记。只有玩家没有历史与历史查询失败是不同状态；不得用全零填充冒充实测低表现。英雄分路先验只可由训练窗口内已经结束的比赛计算，校准/测试标签不可进入先验。完整模型须验证部分成员历史缺失、新英雄、位置未知和地区变化，而不是只验证十人历史齐全。

## 局内第一版输入

必须先确认每场每分钟双方各五名唯一玩家，并且以下字段完整可读：

| 特征 | 定义 | 数据要求 |
| --- | --- | --- |
| 时间 | `time / 60` | 本次快照时刻 |
| 平均等级差 | 蓝方等级和÷5 − 红方等级和÷5 | 10人等级均已知，常规模式范围1–18 |
| 补刀差 | 蓝方补刀总数 − 红方补刀总数 | 历史minions+jungle；与2999 creepScore含义需实测核对 |
| 击杀差 | 蓝方击杀和 − 红方击杀和 | 10人公开击杀 |
| 死亡差 | 蓝方死亡和 − 红方死亡和 | 10人公开死亡 |
| 助攻差 | 蓝方助攻和 − 红方助攻和 | 10人公开助攻 |

资源与装备在后续补足“历史、实时可对齐”的证据后增加。精确totalGold/currentGold、XP、伤害、视野、坐标、双方技能冷却不进入该局内基线。当前玩家可读金币也不能代替双方等价口径。

装备价值需同版本价格、库存重建、任务/免费升级/消耗与撤销处理；缺少价格或事件时标记未知，不用最新版本价格回填。资源需确认归属、时间、去重及历史完整性；未知击杀者不默认红或蓝，水晶按可确认状态处理，不把累计击破数等同当前仍未重生。

## 独立划分

目前公开候选缺少开局时间，因此使用明确的补丁留出：早于16.17的比赛训练，16.17校准，16.18及以后测试。此划分只说明跨补丁检验，不等同严格逐日向前验证。不能从match ID大小或文件顺序推断比赛先后。

同一比赛不能出现多个补丁或冲突标签。未来获得完整日期后，改为时间窗口划分并固定训练、校准和最终测试，不以测试集挑选模型或超参数。

## 模型、校准与指标

- L2逻辑回归固定迭代160次，L2系数0.01，初始步长0.3，训练集标准化；参数在看最终测试之前确定。
- 用训练胜率构造常数基准，与逻辑回归和独立sigmoid校准后的输出比较。
- 校准器仅使用校准集，正斜率保留原始排序；不根据最终测试集选择是否采用校准。
- 汇报Brier、Log Loss、ROC AUC、0.5阈值准确率、10个可靠性分箱及ECE。低Brier或低ECE均不能单独证明生产概率可靠。
- 同场多快照训练、校准和指标均采用每场等权。局内还需分5/10/15/20/25/30分钟报告，不能用临近结束快照拉高整局指标。
- 缺少独立完整数据时报告不可评测，不以合成数据指标替代真实成绩。

## 复跑命令

在Windows原生Node.js24、项目根目录执行：

```powershell
node scripts/win-probability/fetch.mjs
node scripts/win-probability/audit.mjs
node scripts/win-probability/evaluate.mjs
node --test tests/win-probability-offline.test.mjs
```

支持`--root <目录>`指定离线研究目录。每次审计重新核对原始文件SHA-256；原始文件不全、哈希不符、样本跨集合或标签冲突均失败。模型输出文件标记`productionReady:false`，没有客户端自动加载入口。
