# 排位推荐与配置参考

单双排、灵活排位会自动显示双方公开选人；未知英雄保持空位，未公开分路标为未确认。排位不使用大厅预选或“参考预选”开关，匹配仍保留原有流程。已锁定英雄不能换成另一个英雄，推荐、提议和投票仍可继续。

配置页的“选人应对”会随公开选人更新，比较当前英雄、当前分路已有的完整符文页与装备组合。它是机制建议；采用只改变选中的字段，保留后期装备、鞋子、D/F 等其他个人选择，点击应用才写入客户端。没有新建议时继续保留当前配置。

双方十位英雄都锁定后，阵容页用时间走势替换提议区；配置页提供跳转入口。**这是各队英雄分路历史统计的均值参考，不是本场预测胜率。** 两条线独立计算，不强制相加为 100%。分钟表示历史对局的结束时长区间；来源未提供区间样本量，不绘制伪造的置信区间。数据不齐时明确显示暂无完整统计。

## 推荐怎样考虑对手

- 原有己方配合、英雄池、人数和风格约束继续生效；公开敌方的阵容机制作为补充。
- 明确公开的位置直接使用。未知位置按来源一次返回的完整分路场次分布，枚举最多 120 种五路分配，计算位置权重。常见分路是估计，不被写成客户端实际位置；缺少分布时保持均匀未知，不把未下载的位置当零场次。
- 对位项使用 OP.GG 对应分路的对手表作为有限排序参考。先用双方分路基础胜率的 log-odds 差扣除基础强度差异，再对对手表与该基准的差值做 `n / (n + 1000)` 收缩。小于 30 场不使用，原始差值限制在 ±8 个百分点，再按分路权重与 0.5 的规则系数计入，单个成员总调整不超过 ±4 分。多成员取平均，避免人数越多加分越大。
- 这些系数是保守的排序规则，未通过当前补丁的逐局训练与校准。它们不构成本场胜率，也不证明某个英雄是最优选择。历史未知口径的表不会自动获得对位评分权限。
- 选人过程中预取所需公开参考；已有本地数据时推荐与曲线都在本机计算。倒计时不改变推荐身份，不为每个时钟跳动重算一轮。

灵活排位目前沿用来源的单双排统计，并明确标注；不会把它说成灵活排位专属样本。没有当前版本、地域或段位的统计时，相关统计项不参与，不静默换成其他来源。

## 配装数据修正

已重新采集 16.20 的 173 位英雄、309 个有效分路配置。峡谷与海克斯都可自动补齐当前英雄所选来源，过期缓存保留作离线参考并标明获取时间。缺少来源时，点击英雄先完成选人，再获取配置；取得对应来源前不会自动写入通用备选符文。

OP.GG 的三件核心、鞋子、完整符文分别统计，不是完整购买顺序或装备符文联合胜率。亚索、永恩的首件核心不含攻速且选择狂战士胫甲时，将攻速鞋提前列入目标，并明确这是机制安排。不会为了“打野不该带不灭”的印象删除合法来源页：当前蝎子的高样本完整页可以是不灭。

## 调研与依据

- [Riot 开发者文档](https://developer.riotgames.com/docs/lol)：仅使用公开游戏资料和本地客户端公开接口，不读取隐藏信息或游戏内存。
- [DraftRec](https://arxiv.org/html/2204.12750)：同时考虑玩家偏好、队友配合与对手，提醒单纯按热门英雄排序的局限；本项目没有声称使用论文模型或旧补丁权重。
- [A Confidence-Calibrated MOBA Game Winner Predictor](https://arxiv.org/abs/2006.15521)：预测胜率需要处理未观测因素并验证校准，不能将机制分数直接当概率。
- [公开排位特征研究](https://baronbuff.com/blog/features_weights)：区分对线、其他敌人、队友协同与英雄基础强度，按对局分组验证，避免玩家行之间的数据泄漏。
- [OP.GG 亚索中路对手表](https://op.gg/lol/champions/yasuo/counters/mid?region=global&tier=emerald_plus)、[分时统计](https://op.gg/lol/champions/yasuo/trends/mid)：用于核对公开分路表与时长区间；不推断本局未知分路或玩家水平。
