# 0.59.0 · 优先推荐常玩的英雄

已发布：[下载页](https://room.riftbuddy.dpdns.org/downloads/) · [GitHub](https://github.com/Legender134/rift-buddy/releases/tag/v0.59.0) · [Gitee](https://gitee.com/legender134/rift-buddy/releases/v0.59.0)。三个入口的完整安装包字节一致。

- 连接客户端后，先统计本人最近最多 500 场的英雄次数，再加载“历史战绩”；两个窗口共用一次采集，分批读取即可参与推荐。
- 已玩英雄按场次分配默认 85% 偏好，未玩英雄合计 15%；在“历史战绩 → 推荐偏好”调节。不足 500 场按实际有效记录，无历史时均匀参考。
- 同组队成员各自归一化再合并探索，不让总场次多的人占更大权重。明确成员位置仍用本人的偏好，不把队友的常用英雄当成本人的；禁选、分路、拥有范围、锁定与配合质量优先。
- 房间仅共享本人有界英雄场次摘要和比例，不发送逐局战绩、玩家标识、备注或凭据。换号、断线和离房会撤销对应偏好；旧房主或中继无摘要能力时不发送，可在房间共享说明查看可用人数。
- 统计更新不打断搜索输入或滑动条操作。英雄偏好只改变候选探索和选择，不增加契合分，不是胜率或固定展示比例保证。

保留 0.58.8 的增量更新修复。从 0.58.8 升级约 611 KiB，0.58.7 约 619 KiB；0.57.1、0.57.3 的过渡补丁分别约 3.18 MiB、2.93 MiB。四条补丁均已实际提取、原生还原并逐文件校验；已发布 0.58.8 的更新器实测选择增量，没有请求完整安装包。首次安装、运行库变化或本机文件校验不符时仍可能需要完整包。
