# 局内小卡与独立加点提示

默认指引显示有顺序的完整成装，组件清单在“详情 → 购买”中查看。辅助另留任务装位置；下路第七件需要本局正式下路任务完成后，在详情中明确确认。未确认的第七件不会成为下一件购买目标。

小卡可以拖动、关闭，通过托盘或快捷键恢复。加点提示是独立单行，显示前三点顺序与主副技能，例如`W→Q→E · 主W 副Q`；当前可升技能与依据放在悬停中。默认放在游戏下部中央、技能栏上方，可以拖动、调整宽度，单独关闭并从小卡“加点”或详情加点页恢复。完整指引仍保留一级首点建议。关闭装备卡可单独保留加点提示。助手只显示参考，不操作游戏加点。自定义HUD、缩放和全屏模式仍需玩家核对，真实多屏混合DPI尚待实测。

实际对局的左上角另有四排微窗：我方头像、我方装备价值、敌方头像、敌方装备价值。只显示公开已持有装备的标价总和，不是钱包金币；数据未读全时显示`—`，不填零。右侧保留当前配置；海克斯仍优先显示强化图标，其次装备。设置中可独立开关装备价值、配置、加点、打野规划，也可关闭开局自动显示或赛后评分。关闭开关即时隐藏，重新开启恢复原显示意图；手动关掉的小窗不会被轮询重开。

装备卡关闭只作用于本次运行；重启助手时，可按“进入游戏自动显示”设置重新显示。加点窗的关闭状态和位置会保存，关闭后需主动恢复。

完整装备路线保留选人准备中的组合核心和个人自选。空余后期位置从当前路线兼容的完整装备备选补齐，不把独立装备统计合成为六件套胜率。少量备选说明适用条件及代价；“条件备选”并不代表已经识别到对应威胁。

普通峡谷的本局英雄、背包、队列和双方公开装备均确认后，可以按公开装备投入与玩家标记调整尚未购买的后续目标。例如需要持续处理护甲目标时比较穿透成装，魔法压力较大时比较适合路线的魔抗装备。已有成装、个人备选、前两件组合核心和已经投入较多组件或可完成的下一目标受到保留；每次至多调整一项，不自动购买、出售或覆盖保存的选人方案。它没有敌方实时抗性、技能冷却及伤害来源全量数据，不保证最优出装。资料或规则版本变化、接口中断、未知队列时暂停调整。

“野区与资源 / 资源节奏”可查看梦魇、皎月、翠神的开局机制和营地顺序，其他打野提供可调整的蓝/红起手示例。翠神使用画圈与成熟释放的专门步骤，不能当普通攻击六营路线。路线不推断已清营地、野怪血量或敌方位置，也没有16.20最优清野时间的对局证据。

抓人取舍可由玩家选择一条路，并确认敌方压出、队友能跟、控制可靠、进退安全，再与继续刷野、补给和资源准备比较；条件变化时取消，90秒后旧标记失效，新局清除。助手使用本人实际生命与已学技能避免把尚未学会的大招写成当前连招，无法确认兵线时保留判断条件。小卡在已核对的资源出现前一分钟提供简短准备入口，计时到达不宣称资源仍在或敌方正在开打。

没有敌方施法和位置数据，不能检测来抓、正在打龙或真实技能冷却。Riot当前游戏完整性规则及25.17说明限制敌方大招/召唤师冷却追踪；OP.GG已经撤下相关功能，本产品不实现手动或自动敌方冷却计时。
