# 窗口大小、位置与暂时收起

主窗口、选人侧栏及局内的装备卡、加点提示、野区规划可以分别调整。默认仍使用小窗口，优先保留游戏视野。

v0.47 起选人主窗与独立侧栏同时存在；打开完整助手不会关闭侧栏。自动贴边默认宽 440 逻辑像素，高度与客户端一致，1–2 逻辑像素观测抖动不反复改变边界。进入游戏后释放选人侧栏；主窗先自动隐藏，等待进行中的操作与保存完成后释放界面进程。托盘、快捷键和指引可重建完整助手，游戏期主动打开后保持；返回大厅或选人时自动重建，已保存的配置与位置保留。

- 主窗口和选人侧栏：拖动顶部移动，拖动边缘调整大小。侧栏一旦手动调整，会保存尺寸和位置，下次选人沿用，不再自动贴回客户端。切到其他应用时取消选人侧栏的置顶。
- 局内小窗：拖动顶部移动，用右下角 `◢` 调整大小。各窗独立保存，重新打开时恢复；屏幕变小或旧屏幕断开时限制在可见范围。
- `‹` 或主窗口的“收起”：暂时隐藏该窗，在屏幕边缘保留小拉手。点击拉手恢复收起前的位置和尺寸。三个局内小窗可分别收起，不会关闭其他小窗。
- `×`：关闭该窗。局内装备卡上的“加点 / 野区”可恢复相应模块；托盘或快捷键可找回本局指引。

在“选人与侧栏设置”可以选择“重新跟随客户端”“恢复侧栏默认布局”或“恢复全部窗口默认布局”。更改自动跟随宽度也会重新启用跟随。

“恢复侧栏默认布局”恢复 440 逻辑像素的自动贴边侧栏；客户端旁空间不足时保持宽度并移到屏幕内，可能与客户端重叠；屏幕本身更窄时才缩小。“恢复全部窗口默认布局”另清除主窗口与局内小窗的自定义尺寸和位置，并恢复默认装备卡、加点和野区提示。局内“字号与指引设置”中的“恢复默认窗口布局”只重置局内窗口。“恢复默认”字号与内容按钮另行控制字号和模块顺序。

布局恢复不会改变英雄、阵容、符文、出装、收藏或已标记装备。窗口调整只作用于助手，不修改游戏分辨率或客户端窗口。独占全屏、物理前台闪烁与混合 DPI 的真实对局效果仍待玩家验证。
