# 0.59.4 · 敌方分路与推荐上下文

已同步发布至 GitHub、Gitee 与[下载页](https://room.riftbuddy.dpdns.org/downloads/)，三处安装包字节一致。0.59.1 升级补丁为 **614739 字节，约600 KiB**；另提供 0.59.0、0.58.8、0.58.7、0.57.3、0.57.1 直达补丁。

- 匹配锁定自己后显示个人时长曲线，五位队友锁定后显示全队；排位双方使用互补曲线，悬停查看具体值。聊天配置播报默认开启，保留已有关闭设置及本人点击校验。
- 敌方选人固定按五个位置排列，自动联合推断，避免多个英雄挤在同一路；明确区分公开、推测和手动位置。
- 点击分路可调整，位置冲突时交换；一键恢复自动。调整只作用于本局当前英雄，换人、断线或换局后清除。
- 推荐、对位、时长曲线和配置建议使用一致的分路约束；调整后旧计算与旧建议失效，不沿用旧对位。
- 修复两窗并发与延迟保存覆盖问题，保存失败保留已接受状态。

推测分路不冒充客户端实际分配，未公开英雄保持空位。曲线仍是历史数据参考，不能当作本局预测胜率。验证只使用隔离模拟客户端。

0.58.7、0.57.3、0.57.1 的旧更新器有归档自检缺陷，请退出助手后手动运行下载页的对应小补丁一次，无需完整包；0.58.7 补丁797063字节，约778 KiB。0.58.8及之后的已验更新器支持应用内增量。
