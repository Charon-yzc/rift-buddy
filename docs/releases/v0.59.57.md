# 开黑搭子 v0.59.57

集中修复选人、输入与窗口恢复体验。本版安装包尚未发布，公开下载仍为 0.59.56。

- 连续点选英雄或切换配置时，旧等待操作不会把新选择切回去。本人的“我的配置”随另一窗口的新英雄和手动分路更新，参考浏览保留原页；锁定仍由你在客户端确认。
- 设置地址、房间昵称和邀请码在后台刷新时保留草稿、焦点与光标，重绘后仍按原保存方式提交；保存失败可重试。
- 弹窗内的键盘焦点更稳定；自动切页不会抢走正在编辑的弹层和草稿。锁定后的自动配置只在选人页打开，进入新一局不会重新弹出上一局的英雄配置。
- 等待匹配时手动关闭侧栏会保持关闭，下一次选人仍自动出现。窗口移动后立即关闭也能记住新位置，贴边后可恢复；局内小窗的点击、拖动和滚轮操作更稳定。
- 下载先等待当前来源保存，等待期间可暂停或取消；保存失败不会偷偷使用旧来源，重新操作仍可恢复。暂停下载显示为可继续状态。
- 反馈冷却与失败提示更清楚，关闭重开时旧响应不会覆盖新草稿。
- 收藏保存冲突时保留另一窗口已保存的内容，失败后可再次操作。
- 冷启动时连续打开会等待初始化完成，再显示唯一可用主窗。客户端断开后可重新连接，取消 Windows 权限确认后仍可主动重试。
