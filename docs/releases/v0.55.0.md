# 开黑搭子 v0.55.0

组队、选阵容和准备配置更自动，侧栏更紧凑。

- 进入选人时按游戏组队人数初始化“我们”，优先同步预选分路。队友选英雄、换位和位置冲突自动让位，推荐人数保持不变；手动点位置圆点才改变人数。
- 分开预选分路与预选英雄：抢位置留在选阵容页，选英雄则准备整套配置并打开配置页。候选和提议里的可选头像直接预选对应英雄，同时准备该方案的符文、D/F 与商店装备集，没有专用配置时使用默认常用配置。保留闪现键位，锁定由玩家完成。
- 配置页先显示当前配置和两套备选，整套一键切换；分路下拉框只用于浏览对应配置。装备与符文图标随窗口宽度均匀分布，说明、数值放在悬停中，加点以“主升／开局”区分。已锁英雄不可替换，仍可换位。
- 顶部圆角方框铺满可用宽度，“我们”使用右上对角线方向的光点；候选和提议头像与顶部同尺寸，取消重复英雄名和分路文字，详情按需展开。
- 新增 18 套可保存的配色，包含 9 套客户端灵感配色；设置和开黑房间旁的“更多”都可打开配色面板，主界面与侧栏即时同步。
- 客户端状态增加可点击圆点：绿色已连接、红色未连接、暖黄色连接中。点击未连接圆点可重新连接，连接中防止重复点击；底栏进一步压低。
- 延续自动组队房间、提议与多选投票、游戏昵称同步、公开选人同步和自动推荐。
