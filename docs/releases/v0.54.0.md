# 开黑搭子 v0.54.0

**选好阵容，一起开黑。**

开黑搭子是一款面向英雄联盟朋友开黑的 Windows 桌面助手。从组队大厅到选人、配置，再到对局中的参考，把需要的准备放在顺手的位置。

## 这一版带来什么

- **先选阵容，再准备开局。** 二至五人推荐围绕“我们”的位置展开；单人时参考公开队友，只更换自己的选择。已选英雄、手动位置和队友选择优先保留。
- **点一次，准备好配置。** 点击本人推荐英雄，预选并准备符文、D/F 和商店装备集；默认保留闪现键位，最后锁定由玩家确认。预选位置只用于占位，继续留在阵容页。
- **让每位队友知道怎么配合。** 房间可分享候选、投票和完整配置，方案中保留各成员的行动、成立条件与退出安排。
- **资料更新交给服务器。** 同版本榜单、常用配置和海克斯参考每日两次检查，客户端下载后核验签名和哈希；选人、对局期间暂存，空闲时启用，断网保留有效缓存。
- **选择和配置更连贯。** 修复未锁英雄被误当作固定选择、新方案同步时丢失、清空预选后旧配置重新出现等问题；未知分路队友也会作为真实英雄背景参与契合评估。

## 下载与安装

支持 Windows x64。使用安装程序即可，不需要开发环境。GitHub、Gitee 和服务器备用入口使用同一份安装包，并提供 SHA-256 校验。

Gitee 因附件限制使用分卷：下载全部 `.part` 和同版 `Merge.cmd` 到同一目录，合并后运行生成的安装包。应用内更新会自动完成分卷下载和校验。

## 使用前了解

- 契合分和配合说明是有依据的机制参考，不是组合胜率或对局收益承诺；排行榜保留其原始地区、段位和统计时间。
- 助手不会自动锁定、购买或升级技能，也不会读取游戏内存、检测敌方来抓或真实技能冷却。
- 已有非标准槽位顺序的旧设置重新生成部分三人方案时，个别个人修改可能无法自动召回；已采用方案和完整收藏恢复不走这条重新生成路径。需要时重新选择配置并保存。
- 已通过回归测试、打包模拟和真实资料下载验证；真实国服兼容、整局性能、物理多屏 DPI 和异机房间仍需玩家实测反馈。
