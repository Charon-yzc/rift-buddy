# 开黑搭子 v0.55.1

预选更清楚，推荐只依据已锁定的英雄。

- 预选英雄只显示意向；包括客户端尚未确认的英雄，均不固定推荐和契合评分。客户端确认锁定后才纳入阵容依据，锁定头像左上角显示锁，仍可换位。
- 顶部队伍头像仅作展示，删除空位加号的手动选英雄功能，改用人物图标。选择英雄仍从预选、候选或提议头像进入，并准备对应整套配置。
- 预选头像右上角增加 ×，取消英雄时保留分路和人数。英雄选择面板提供取消、紧凑搜索与分路筛选；搜索只保留一个外框焦点。
- 未锁定预选的变化不会撤销已采用的阵容；配置页跟随当前预选英雄，避免显示上一位英雄的配置。房间提议也只用已锁定英雄判断冲突。载入收藏后保留本次配置，旧预选不会抢回配置显示。
- 更新 README 与本版截图。继续支持自动连接同一组队房间、人数同步、推荐、整套配置切换和 18 套配色。
