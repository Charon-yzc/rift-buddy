# 0.59.6 · 资料同步与配置决策重构

当前源码版本；安装包在本地验收，公开下载仍为 [0.59.4](v0.59.4.md)。

- 将窗口资料收进统一状态模块：启动前订阅更新，按版本连续接收；漏帧时恢复完整快照，迟到回包不能覆盖新资料。
- 基础资料、组合库、图片索引与出装来源按实际依赖更新，无关统计刷新不再重复初始化它们；窗口选择的来源独立保留。
- 将本人、预选、队友预览及采纳方案的配置决策提取为独立模块，同次同步渲染复用完整配置。点击应用及异步返回后仍读取最新状态，保留个人配置和 D/F 偏好。
- 修复同版本组合文案修改后旧推荐仍可能保留的问题；资料检查与采用也统一等待已接受版本。

本轮重构资料状态与配置派生两条链路，未改变阵容评分算法或扩大自动写入范围。仅使用隔离状态与模拟客户端验收。
