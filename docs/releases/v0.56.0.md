源码已更新，安装包需按发布流程单独验收与发布；公开下载仍以发布页版本为准。

- 风格旁新增“参考预选”，默认关闭；锁定英雄始终作为阵容依据。
- 预选位置/英雄配齐配置并留在阵容页，客户端确认锁定后再打开配置。锁定后仍可推荐、提议、投票，不能更换自己的英雄。
- 提议仅展示实际参考的成员，昵称固定宽度、悬停完整显示；契合分悬停逐项解释。
- 扩展消耗、保护、持续输出与边带等战术覆盖，减少重复英雄，同局稳定、跨局有变化。
- 主界面、随行窗口、图鉴、版本改动、设置与海克斯说明进一步紧凑，详情按需展开。
- 新增后续增量更新支持及安装替换/恢复流程，保留收藏和个人资料。从 0.55.1 首次升级仍使用完整包。
