# 0.59.7：增加腾讯国服参考

在“更多工具 → 各路排行”切换来源为“腾讯国服”，选择分路与黄金+、翡翠+或钻石+。点击英雄查看国服核心装备、出门装、鞋、后续装备及完整符文页；主窗口和随行窗口均支持。原有 OP.GG 默认来源和已选配置不变，国服入口仅供查看。

来源为[腾讯101](https://101.qq.com/)公开数据，按当前基础补丁精确查询，显示来源数据日期；无法确认全区、队列及完整样本覆盖。排行和装备未公布场次，不补造样本；符文保留来源场次。装备组合与符文分别统计，不能视为整套配置或阵容的胜率。

国服排行榜使用独立签名渠道，三档段位完整验证后发布，复用资料服务器每天两次的任务与锁。客户端验签并检查补丁、序号和数据日期；无有效服务器渠道时按需查询官方，保留有效缓存。单英雄装备与符文按需读取并缓存12小时，失败不借用其他来源或旧补丁。此来源不参与自动配置、组合评分或概率曲线计算。

这是源码和本地安装包版本；公开下载继续指向已发布的0.59.4。
