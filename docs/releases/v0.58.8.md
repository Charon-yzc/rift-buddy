# 0.58.8 · 修复有补丁仍下载完整包

- **真正命中增量。** 修复 Electron 将程序归档视为虚拟目录、导致更新器误判本机文件不匹配的问题。现在直接校验物理安装文件，不改变应用其他部分的归档读取行为。
- **多个旧版都能升级。** 同一发布可同时提供多个旧版本的小补丁，生成后一个补丁不会丢失前一个版本的更新入口。校验不匹配或文件被改动时仍禁止复用。
- **按真实运行环境验收。** 新增真实 Electron、有效 ASAR 归档的打包回归：必须选择增量、不能请求完整包，并验证下载后文件被修改时拒绝安装。

**已经安装 0.57.1、0.57.3 或 0.58.7：** 在[下载页](https://room.riftbuddy.dpdns.org/downloads/)选择与你当前版本对应的小补丁，关闭助手后运行。旧版更新器自身有缺陷，需要这次小补丁先修好；无须重新下载完整安装包。之后适用的更新会自动选择增量。首次安装、运行库大幅变化或本机文件校验不匹配仍可能需要完整安装包。

个人设置、收藏与配色保留。验收仅使用隔离安装目录、模拟网络和安装交接，不操作真实客户端或玩家安装。
