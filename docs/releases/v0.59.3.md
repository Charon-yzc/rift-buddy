# 0.59.3 · 匹配曲线与双方相对走势

当前源码验收中，公开下载为 0.59.1。

- 本人锁定后，选阵容页显示英雄时长走势；五位队友锁定后，匹配也会显示全队曲线。
- 排位双方使用同一相对模型生成互补曲线，显示数值相加为 100%。这是历史数据的相对参考，尚未校准为本场胜率。
- 曲线使用平滑连接，鼠标悬停或键盘聚焦可看五个真实时长区间的具体数值；不补造早期样本、分钟节点或区间场次。
- 排位默认参考全队，匹配默认参考“我们”；保留当局手动选择与本人位置。敌我阵容采用不同底色。
- 聊天配置播报默认开启，保留已有关闭设置；仍须本人实际点击配置，并通过当前对局与配置校验后才播报。

数据缺少当前分路、补丁或所选来源时明确留空。算法与边界详见[排位参考说明](../ranked-recommendations.md)。敌方分路的手动编排仍在后续优化范围。
