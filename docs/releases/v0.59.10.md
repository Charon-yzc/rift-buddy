# 0.59.10 · 先选英雄，只看提议

- 点英雄头像时，先发送本人的选人请求，再完成配装和保存。复用近期已验证的客户端连接，减少重复同步、Windows 进程发现和磁盘保存造成的等待；缺失或过期的候选范围仍先刷新。
- 本局、本人操作、锁定、禁选和可选范围仍在主进程实时核对。只预选，不替玩家确认锁定；客户端或凭据变化后停止，不自动重试写入。
- 阵容列表只显示成员明确点击“提议”的方案，保留投票、提议人、契合分和具体配置。移除旧“队友分享的阵容”列表及“重新分享”入口，自动同步状态和旧版队友的阵容快照不再生成另一份列表。
- 房间页保留紧凑成员状态及英雄偏好同步，提议与配置核对继续使用原有协作协议。

本版安装包暂保留本地；公开下载仍为0.59.8。延迟测量和客户端操作测试均使用隔离模拟，不代表真实客户端在所有状态下的响应时间。
