# 0.59.9 · 常用英雄本地缓存

- 自动保存本人英雄场次汇总，按账号和大区隔离。重新打开助手并确认当前账号后，即使战绩接口维护，也能继续参考上次统计推荐。
- 缓存与逐局战绩分开：只保存有界英雄场次，不落盘比赛详情、玩家标识或凭据；不进入收藏备份或安装包，最多保留六个账号/大区摘要。
- 在“历史战绩 → 推荐偏好 → 导入我的统计”导入本人场次文件。当前赛季截图会单独标明来源与日期，未展示英雄不标成未玩过，不伪装为最近500场。
- 完整的新统计替换旧缓存，不叠加重算；刷新未完成或接口失败时保留原有统计。默认85%偏好及房间内的成员归属不变，滑动条仍可调整。
