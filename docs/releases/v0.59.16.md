# 0.59.16 · 装备法强公式

修复装备公式解析器漏掉默认法强属性的问题。依据内置 16.20 客户端字段，补齐纳什之牙、巫妖之祸、黯炎火炬等49条装备记录，含部分模式变体；29条从部分解析变为完整解析。未知数值仍明确标注，海克斯模式调整未经核对时仍显示峡谷基础值。

例如纳什之牙的攻击特效显示为 **15 + 15%法术强度**；巫妖之祸保留 **75%基础攻击力 + 45%法术强度**，不混淆基础、额外和总属性。主窗、侧栏和本局指引共用这些资料。

同版本旧缓存不会覆盖新版内置公式；较旧内容修订的签名资料也不能回退当前资料。近期核对过的旧资料只补取装备公式，不重复读取全部英雄；缺少已核对字段时保留原资料并等待重试。游戏版本更新仍可正常启用，选人期间继续暂存。

这轮没有把 16.20 资料标成 26.21。当前阶段安装包与增量补丁保留本地，公开下载仍为 0.59.8。

另修复保存普通偏好时偶尔把手动预览指引切回本局英雄的问题。这条保存流程排队期间若用户另开指引，旧任务会让路；正常客户端选人同步仍保持自动。
