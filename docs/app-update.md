# 软件更新

升级会先验证新版文件，再停止旧进程、卸载旧程序文件并安装新版，保留收藏和配置；失败时尝试恢复旧程序。新版启动后自动清理自己的旧更新包和中断残留，安装器刚退出导致文件占用时稍后重试。有效待安装包和暂停进度继续保留；不会扫描或删除玩家下载目录里的其他文件。应用内不安装与当前相同或更旧的版本。

v0.46.0 起可在「设置 → 软件更新」检查本仓库的 GitHub Release（包括预览版）；v0.51.0 起同时检查 Gitee 国内镜像。启动检查默认开启，每天最多一次；离线时静默保留当前版本。检查不会自动下载或安装，旧版安装包仍需手动升级一次才能获得此功能。

发现新版后点击「下载新版」。忽略此版只关闭后台提醒，手动检查仍可重新下载。设置中提供 GitHub 与 Gitee 两个下载入口，并可选择「优先 Gitee 国内镜像」。两个发布源分别读取版本，旧镜像不会遮蔽 GitHub 新版；GitHub 不可达时仍可使用 Gitee。Gitee 根据同版清单自动逐段下载、合并，核对每段和完整安装程序的 SHA-256，不执行下载页的合并脚本。旧镜像没有自动更新清单时，提供网页手动下载入口。

GitHub 默认经第三方代理下载安装包，失败回退直连；校验文本直接从 GitHub 获取。Gitee 校验从同版镜像清单获取。哈希只证明与对应发布文件一致，不是签名认证。镜像速度及可用性不保证。

下载完成后点击「退出并安装」。助手会再次校验文件，确认安装进程启动后退出，由玩家按安装向导完成操作。启动失败保留助手和有效安装包，显示原因并允许重试；同一时刻只启动一个安装程序。校验失效时清理文件，需重新下载。已下载的有效新版可在下次检查时离线恢复。

下载和校验时可取消；磁盘写入或保存记录失败会停止并尝试回收临时包，不因本地故障换源重下。下载完成后可删除安装包；若文件被占用导致删除失败，会显示错误并保留记录，解除占用后可重试。安装交接期间不接受检查、下载或删除等冲突操作。

维护者每次发布必须同步 GitHub 与 Gitee。GitHub 上传 `RiftBuddy-<版本>-Setup.exe` 与 `SHA256SUMS-<版本>.txt`，后者由 `pnpm installer` 自动生成。缺少校验文件会拒绝安装，不能绕过校验补救。Gitee 使用 `node scripts/package-gitee-mirror.mjs` 生成小于单附件限制的分卷、合并脚本和清单，最后上传清单，全部附件下载校验后才标记同步完成；历史版本保留。下载跳转限制在 GitHub 资产域名、Gitee 官方 CDN 及配置的代理域名，解析结果不接受本机、内网或保留地址。

自动验收使用隔离用户目录、模拟网络和安装进程；`node scripts/smoke-package-app-update.mjs` 验证打包版发现、校验、续装及镜像回退，`--handoff` 验证异步启动失败重试和并发安装保护。不会执行真实安装器。Windows 防护拦截、真实覆盖升级、快捷方式与重启后的版本验证仍需实际安装验收。
