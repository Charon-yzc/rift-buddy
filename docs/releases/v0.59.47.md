# v0.59.47 · 峡谷组合与推荐

这版更新峡谷组合、推荐评分和内置游戏资料。

- 内置 370 组峡谷方案：282 组双人、88 组三人。保留成员分路、来源、执行条件及对应配置，按当前机制与装备规则判断是否可用。
- 补齐烬与婕拉、泽拉斯的实际伤害标记接控。按已核技能条件识别，不能把植物攻击、技能蓄力或落空当作触发成功。
- 保护短轮输出也能形成共同战术，减少仅因缺少“持续输出”标签而低估法师等搭档。持续输出缺口仍独立保留；不会因为来自组合库就直接加分。
- 通用计划与具体技能接力择高计分、不叠加，具体技能条件独立显示。资料缺失不会借回退路径取得更高战术分。
- 随包更新至 16.22.1 的基础资料、分路配置、排行和海克斯参考。旧补丁的海克斯社区路线继续隔离，不作为当版可执行攻略。

契合分是规则评分，不是组合胜率。推荐继续遵守锁定英雄、公开禁选、可选范围、玩家偏好和手动分路；低于 60 分的数值候选不展示。安装包中的资料离线可用，后续签名资料在空闲时启用。

这是 0.x 更新，不作为 1.0 正式版。
