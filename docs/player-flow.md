# 选人和局内小窗

## 0.47 实玩反馈改进

选人主窗和贴边侧栏同时保留；主窗左侧是当前队伍，右侧直接比较六个候选。侧栏也先看全队与精简候选，采用前只显示英雄、位置、配合摘要和必要风险，点击“详情”才展开完整职责。采用或确认英雄后，再看当前组合的具体准备。

选人会话编号优先于尚未更新的游戏流程编号，避免正常点击被误判为另一局。已采用组合的预选、重复应用与玩家确认继续使用相同符文、D/F、装备集；明确选了另一行动路线才改为对应配置。主窗候选英雄和队伍头像、侧栏英雄均遵循“点击英雄就预选并配置”设置；图鉴与配置库浏览不会写入客户端。两个窗口同步已保存准备和实际配置结果，失败仍逐步显示，不会自动锁定、购买或升级。

装备卡直接显示下一件用途，三条备选显示适用条件；点击备选只是设置回城目标，不会购买或改动保存的整套路线。用途按随包 16.20 装备说明整理，不宣称社区共识或最优收益。详细依据、金币、小件仍在详情里；资源倒计时不再挤占默认装备卡。

## 0.44 选人侧栏与队友方案

未选英雄时，首屏先看全队与“推荐阵容”。选好本人的英雄、采纳组合或收到队友方案后，默认切为五位置紧凑概览；自己的配置动作和当前配合职责放在前面。完整分工、失败条件、其他推荐、符文与出装向下展开。可选范围核对失败仍在前面提示，已核对的详细范围移入“可选英雄与来源范围”。底部保留配置状态与本局指引，“更多操作”可单独替换符文、同步客户端、查看窗口资料或改变自动指引。

点击全队概览中的本人英雄或其他本局可选英雄，会按“点击英雄就预选并配置”设置操作；已经被队友选定的英雄只查看配置。一键配置成功后回到全队和当前职责，失败时保留详细结果供处理。本人已锁定时只可应用当前英雄的新配置，不会换英雄或自动锁定。拖动仍可换位，也可点独立的“换位”；“我们 / 队友”仅修改开黑标记。在“选人与侧栏设置”关闭“选定方案后紧凑显示全队”即可恢复逐行阵容。

收到的队友阵容直接出现在选人页，点击“采用阵容”只改变助手里的安排，不写入客户端。当前公开已选、手动位置、手动锁定和公开禁选会优先保留；冲突的成员、职责或无效配置明确提示未采用。同版本的有效完整配置会保留装备顺序、符文、召唤师技能和已有加点，随后点击本人的英雄才进行客户端配置。没有收到配置时使用本机参考，不能称为队友的原配置。

默认中继现已支持完整阵容、配置和分工，新版助手会完整发送；旧版队友或其他中继仍可能缺少字段。消息缺少模式时，仅当助手已连接当前峡谷选人，可由本人点击“按峡谷采用”明确选择本次用途；其他状态先查看分享。没有收到的配置不会显示为队友所选。相同内容的重复发送不会再次顶出刚采用的提示，内容改变后会作为新方案显示。跨网络双方真实客户端联动仍待用户验证。

默认先显示眼下要做的事，详细配置和依据往下看。所有客户端写入必须由本人点击，英雄只预选，不会自动锁定、升级或购买。

## 在选人侧栏完成准备

1. 首屏显示五个位置和客户端公开已选英雄。没有分路时按当前选用缓存的同版本分路样本排序；没有可比样本时使用英雄位置机制参考。冲突依次安排空位，“暂排”不代表正式分路，可拖动交换。客户端已选英雄会保留，更换请在客户端完成。
2. 助手在进入选人前读取大厅公开预组队成员，随后匹配当前我方公开身份。中途启动、接口失效或身份隐藏时不能完整识别。在设置补充 `昵称#标签` 或公开数字 ID，或直接点位置旁的“我们 / 队友”。手动标记优先；不读取聊天消息，不恢复隐藏身份，不向房间发送玩家 ID。
3. 点击“推荐阵容”，再点“就试这套”采用和分享。首屏出现该组合的配合窗口和职责。点击其中自己的英雄，即可预选并配置对应默认符文、D/F 和商店装备集；无专用配置的部分按本机当前参考。客户端允许时可改预选；已经锁定其他英雄则停止。玩家仍须在客户端核对后锁定。
4. 房间标签可连接队友。收到的阵容出现在侧栏；默认点击本人可用的英雄准备。收到同版本完整配置时保留其符文、D/F、已有加点与出装顺序；收到阵容但无配置时明确使用本机参考，模式缺失时先确认用途。默认公网中继已支持完整分享，需使用 0.44.0 或更新的助手；也可使用局域网、自建中继或私发准备文件。

“选人与侧栏设置”可选择 400 / 440 / 480 / 520 / 600 逻辑像素宽度，默认 440；已保存的其他宽度仍保留，恢复默认才改回 440。客户端旁空间不足时保持所选宽度，移到屏幕内，可能与客户端重叠；只有屏幕本身更窄时才缩小。可关闭点击直接配置、自动暂排或自动标记成员。关闭点击配置后仍可查看方案，并明确点击“客户端预选并配置”。每次会覆盖一张可编辑符文页，优先复用上次写入页，其次当前可编辑页，不改预设页。失败后停止后续步骤并分别显示结果。

采用队友完整配置后，个人出装顺序保留到局内与再次分享；修改符文不会清掉出装。在侧栏装备区或详细配置点击“恢复本机出装”，只恢复当前英雄、位置和组合的本机装备参考，保留自己的符文、加点和 D/F。更换玩法配置则按该玩法重新选择默认配置。

侧栏跟随客户端和助手的前台交互状态置顶，切到其他应用后取消置顶。未变化的轮询只更新倒计时，保留当前 DOM、滚动和输入；公开选人变化时更新内容。物理混合 DPI、真实客户端前台切换和闪烁改善仍需实测。

## 局内按位置显示

- 默认装备卡约 320 × 214 逻辑像素，先看下一件、成装顺序和少量备选。金币、小件、双方装备与详细依据在详情。按公开装备压力调整后续建议，已购装备与组合核心优先保留；没有敌方具体威胁的完整量化模型，不宣称最优出装。
- 加点提示独立放技能栏上方，约 208 × 48；不挡技能栏。可拖动顶部、关闭，装备卡“加点”按钮恢复。显示的是合法加点参考，实际升级由玩家完成。
- 本人峡谷打野指引另有约 250 × 144 的野区规划窗，默认在右下小地图上方；可拖动、关闭，装备卡“野区”按钮恢复。读取自身等级、时间、生命和已学技能；路线是机制示例。兵线四项条件由玩家观察确认，90 秒后失效，不根据未确认的兵线指定抓哪路。
- “找回局内指引”把装备卡和小窗位置移回当前游戏屏幕。字号可设 100%、110%、125%；关闭状态单独保存，关闭装备卡不会关闭其余小窗。独占全屏是否显示、各分辨率是否挡住实际 HUD 仍需玩家验证。

## 明确保留的能力缺口

现有 Live Client Data API 没有敌方坐标、可见性、施法和真实冷却，不能实现可信的敌人距离进入预警，也不能据此检测敌方来抓或正在打龙。不会读取游戏内存、恢复隐藏身份或自动输入游戏操作。敌方大招／召唤师技能追踪受 Riot 当前规则限制，不按旧产品宣传复制。

本阶段修复根据 2026-10-13 用户真实选人和对局反馈，验证采用隔离接口、理论机制及实际打包窗口。修复版本的国服复测、安装升级、双 Windows 跨网完整配置与推荐收益仍为未知；单元测试数量不代表成熟度。
