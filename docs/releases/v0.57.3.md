# 0.57.3 · 可暂停续传的更新与安装后启动

- 下载时提供“暂停”和“取消”：暂停保留进度，继续时续传；取消终止下载并清理临时文件。重新打开助手仍会显示暂停进度。
- 修复进度刷新重建按钮、导致点击取消丢失的问题；文件仍在写入时，停止操作等待写入收尾。
- 增量下载失败先尝试同版本的直连和 Gitee 渠道；暂时的网络错误不再悄悄改下完整包。没有适用增量或本地文件不符合基线时仍需要完整包，下载状态会标明包类型。
- 安装完成页增加“启动开黑搭子”勾选项，勾选后点击“完成”启动。静默安装不自动启动；玩家资料保留。

打开“数据与连接”检查软件更新；有匹配的增量包时自动选用。下载量取决于本地版本、文件完整性与这次修改的内容，并非每次更新都能使用增量。
