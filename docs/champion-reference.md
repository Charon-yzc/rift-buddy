# 英雄图鉴、版本改动与各路排行

从主界面左侧打开“英雄图鉴”，搜索名字、称号、简称或拼音，点击英雄即可查阅。技能图标和文本随应用提供，断网可用。

技能页先显示所选技能的冷却、消耗、数值和作用。斜线数值按技能等级排列；随英雄等级或大招等级成长的内容另行说明。充能恢复与再次施放间隔分开，不能把零冷却的包装技能理解为无限施放。彗的九个子技能、厄斐琉斯的五种武器，以及豹女、蜘蛛、杰斯、纳尔、雷克塞和卡尔玛等不同形态可分别切换。冷却未计算技能急速，资料范围也不保证目标在该距离一定命中。

“近期改动”显示最近三版已收录的召唤师峡谷平衡变化，逐项比较前后值，并区分加强、削弱和混合调整。点击“官方说明”查看原文；从独立“版本改动”页的英雄名称也可直接进入图鉴。没有条目只表示最近收录的三版没有此英雄的峡谷改动，不能推断更早版本或其他模式没有改动。

图鉴的“符文与出装”打开对应英雄的现有配置；配置中的“技能与改动”返回图鉴。查阅资料、切换技能或排行筛选不会写入客户端。预选和配置仍需本人明确点击；锁定由玩家完成。

“各路排行”提供上／野／中／下／辅，支持全球／韩国及黄金以上／翡翠以上／钻石以上六组筛选，可按梯级、胜率、登场率或样本查看。数据来自 OP.GG 聚合统计，显示本组筛选的版本、样本、分析和获取时间。原始来源的 T0 为最高梯级；缺少梯级或名次时保留缺失，不补造。它不是国服榜单，也不能把某位置统计当成组合胜率。

选人侧栏顶部“排行”可直接使用这些榜单。点击本人可选英雄沿用预选与配置功能，成功后回到全队；点已选队友英雄查看配置。榜单的地区和段位只改变榜单，不会改变当前配置来源。刷新失败保留同组缓存，不用另一地区、段位或旧版本的数据填充。

技能资料主要依据腾讯官方详情，冷却和消耗等级顺序取同版 Riot Data Dragon，特殊形态结合同版客户端资料整理。更新游戏基础资料不会自动证明技能语义已复核；若图鉴版本落后会保留旧版并提示。厄斐琉斯断魄中文客户端说明的总伤害公式与另一内部每击系数之间，仍缺少真实游戏结算证据，技能页保留该限制。

维护时可执行 `pnpm sync-rankings` 重新收集六组统计。`pnpm sync-abilities` 收集技能及图标；特殊技能整理按版本设置检查，换版本需复核，不能只改版本号。两者只读取公开资料，不需要游戏账户或凭据。
