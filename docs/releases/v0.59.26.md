# 0.59.26

- 设置中可分别控制经济、装备、加点、打野提示，以及自动显示与赛后评分。关闭右侧装备卡会保留左侧经济窗，轮询不会重新弹出。
- 左上角以四排头像和小数字显示双方公开装备总价值；加点缩为一行“前三点 · 主副技能”，详细信息悬停查看。
- 主界面左下角新增反馈：主动填写文字、选择截图后再发送。最多2000字、3张图合计10MiB，服务端限频并私有保留7天；不自动附带账号、战绩、日志或设置。
- 队友后续选人使提议冲突时，提议会自动消失；修复Gitee保留较多历史版本后漏检新版。
