# 0.59.2 · 战绩读取与搜索优化

本阶段源码已合入，随 [0.59.4](v0.59.4.md) 一起发布；未单独发布 0.59.2 安装包。

- 本人英雄场次摘要仍优先加载，完成后后台加载历史；自动加载保留正在进行的搜索，不反复打开已关闭标签。
- 搜索放在顶部；数据源和大区按需展开。保留常用英雄、可调推荐偏好及紧凑空态。
- 同账号同大区复用完整对局，原始详情、时间线和已处理战绩共享有界内存预算；切换账号或清空时撤销旧缓存和迟到请求。
- 复用客户端连接与短期认证，认证失效后下次重试重新读取。并发时间线保留降级来源说明，取消后不重绘新页面。

保留 0.59.1 的安装失败恢复。仅通过隔离模拟验证，不以模拟耗时承诺真实客户端速度；未测试真实客户端、符文或玩家安装目录。
