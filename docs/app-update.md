# 软件更新

v0.46.0 起可在「设置 → 软件更新」检查本仓库的 Release（包括预览版）。启动检查默认开启，每天最多一次；离线时静默保留当前版本。检查不会自动下载或安装，旧版安装包仍需手动升级一次才能获得此功能。

发现新版后点击「下载新版」。忽略此版只关闭后台提醒，手动检查仍可重新下载。默认经第三方镜像下载安装包，镜像失效、超时或内容不匹配时回退直连并提示；设置中可清空镜像恢复直连。镜像速度及可用性不保证。校验文件始终从 GitHub 直连获取，下载包的 SHA-256 必须一致；这只是与发布文件一致的完整性检查，不是签名认证。

下载完成后点击「退出并安装」。助手会再次校验文件，确认安装进程启动后退出，由玩家按安装向导完成操作。启动失败保留助手和有效安装包，显示原因并允许重试；同一时刻只启动一个安装程序。校验失效时清理文件，需重新下载。已下载的有效新版可在下次检查时离线恢复。

下载和校验时可取消；磁盘写入或保存记录失败会停止并尝试回收临时包，不因本地故障换源重下。下载完成后可删除安装包；若文件被占用导致删除失败，会显示错误并保留记录，解除占用后可重试。安装交接期间不接受检查、下载或删除等冲突操作。

维护者每次发布需同时上传 `RiftBuddy-<版本>-Setup.exe` 与 `SHA256SUMS-<版本>.txt`，后者由 `pnpm installer` 自动生成。缺少校验文件会拒绝安装，不能绕过校验补救。下载跳转限制在 GitHub 资产域名及配置的镜像域名，解析结果不接受本机、内网或保留地址。

自动验收使用隔离用户目录、模拟网络和安装进程；`node scripts/smoke-package-app-update.mjs` 验证打包版发现、校验、续装及镜像回退，`--handoff` 验证异步启动失败重试和并发安装保护。不会执行真实安装器。Windows 防护拦截、真实覆盖升级、快捷方式与重启后的版本验证仍需实际安装验收。
