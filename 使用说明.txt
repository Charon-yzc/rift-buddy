开黑搭子 v0.52.0 · 使用说明
本文对应 v0.52.0；公开下载可能仍是旧版，请以下载页版本为准。安装和卸载不会删除个人收藏、偏好及资料缓存。

默认准备与本人习惯
侧栏“选阵容”先看队伍、本人位置和三条推荐，点“连接队友”可在侧栏内加入房间。更多候选、详情和来源按需展开；收到的队友方案直接出现在选人页。
点自己的候选头像会采用组合、预选并准备配置；点队友只查看。四步分别显示英雄预选、符文、D/F 和装备集的结果。锁定需要你在客户端确认。“换一套”比较助手安排但还未在客户端选定的位置；没有采用新方案时可以返回原安排。
“我的配置”可核对有序完整装备、符文、D/F 和加点，展开编辑具体选项。完整装备路线与实际导入、分享的计划一致；“手动已选”只统计主动换入的后期项。
默认保留客户端当前闪现 D/F 键位，应用时重新核对。侧栏“更多 → 选人与侧栏设置”可指定固定习惯；主动调整配置中的 D/F 也会记住习惯。没有闪现时不交换技能，修改设置不会自动写入客户端，点击预选或配置才会应用。
单独导入装备集只会将“装备集”标记完成；主窗与侧栏同步回执，切换到新一局后重新核对。前排模板可用“普攻压力”切换护甲分支，“魔法伤害”保留魔抗分支；这些是机制参考，不是已验证最优装备。

双击“开黑搭子.exe”。请保留整个文件夹，不要单独移动 exe。
Ctrl + Shift + Space 呼出 / 隐藏助手，Ctrl + Shift + G 呼出 / 隐藏本局指引。
Ctrl + Shift + H 在游戏中切换指引的鼠标穿透 / 可交互状态，也可从托盘切换。
快捷键被占用时从托盘或桌面图标打开。关闭主窗口后仍在托盘运行，右键托盘可退出。

界面与局内概览
主界面顶部“字号”或局内详情的显示设置可选择标准、大字和更大（100% / 110% / 125%），与选人侧栏、局内指引同步，重启后保留。侧栏“更多 → 选人与侧栏设置”调整操作与宽度。
局内默认显示小型装备卡：下一件、完整成装顺序与少量条件备选。加点提示独立放在技能栏上方；本人峡谷打野另有小地图上方的野区规划窗，持续显示首轮或后续半区刷野顺序；红区/蓝区可手动切换，路线按实际营地和安全情况调整。各窗可拖动、单独关闭和恢复，金币、小件、双方装备与更多依据按需在“详情”查看；详情的显示设置可开关概览模块并调整顺序。实际游戏 HUD、独占全屏和混合 DPI 仍需核对。
侧栏收藏按钮显示当前搭配是否已收藏；后期装备不同会保存为独立搭配，打开收藏时恢复所选后期装备。海克斯配置收藏同时保留强化备选、比较选项、已选强化和核心路线。
收藏卡片显示位置、核心出装、自选后期和强化上下文；资料变化后按当前资料还原，并保留原收藏与不可用条目的说明。
侧栏“选阵容”首屏优先查看全队当前选人和推荐，采用后展示本人准备结果与开局任务；“我的配置”中的编辑和来源默认收起。相同方案的展开状态在同步时保留，换到不同英雄不会继承其他英雄的展开状态。刷新失败保留当前参考并说明原因。
双方装备展示当前背包装备的资料标价与回血／重伤覆盖，数据不完整时不比较。装备标价不是双方总经济，不能用来推断未花金币、已出售装备或隐藏信息。
装备卡“详情”可打开完整指引；详情收起后保留速记，点击“展开”恢复。加点窗与野区窗单独控制，关闭装备卡不关闭它们；卡片“加点 / 野区”可恢复对应小窗。主界面或托盘“找回指引”可把位置移回游戏所在屏幕。助手不修改游戏分辨率或窗口模式。

单人与组队选人
左侧“开黑房间”是独立入口，选人窄侧栏顶部也可打开房间。确认“我的位置”后查看自己的方案、各成员配合玩法、完整符文、D/F 和加点；“调整配置”可以分别修改。选择组合默认打开三人套路，也支持两人和更多人数的阵容分析。
房间的本机方案与队友实际分享分别显示。默认中继现已支持完整方案；你和队友需使用0.44或更新版本发送完整的装备、符文、召唤师技能、加点与配合玩法。旧消息缺少配置时会明确提示，不能当成队友所选；也可通过配置文件交换准备。
默认点击侧栏推荐、已采用组合或已确认峡谷模式的队友分享中的英雄，就会在你自己的客户端预选该英雄、替换一张可编辑符文页、设置召唤师技能的 D/F 顺序，并导入对应英雄位置的商店装备集。组合有专用配置时采用该配置，否则使用本机当前来源参考；自己的有效修改优先保留。侧栏“设置”可关闭“点击英雄就预选并配置”，改为只查看，再明确点“客户端预选并配置”。接收分享、查看或修改配置本身不会写入客户端。不会锁定、禁用英雄、自动购买或自动升级技能。已锁定同一英雄时只应用配置，已锁定其他英雄时拒绝改选。
每一步单独显示结果，中途失败会停止后续步骤；已完成步骤保留，请在客户端核对后决定重试。更换方案后可重新应用；只有本人明确点击才写入客户端。实际国服客户端的预选与配置联动仍需实机验证，模拟测试不代表实战验收。
进入选人阶段后，默认在客户端右侧显示窄侧栏；右侧空间不足时放到左侧。
侧栏跟随客户端移动，客户端最小化后隐藏，恢复后显示。客户端或助手在前台交互时侧栏置顶，切到其他应用时取消置顶；未变化的轮询只更新倒计时，保留滚动和输入。真实前台切换与闪烁改善尚待实测。屏幕没有侧边空间时靠屏幕边缘显示，并注明会覆盖客户端边缘。
“选人与配合”显示五个位置的当前英雄、推荐入口和队友分享。点击“推荐阵容”后，候选显示推荐理由、配合和取舍；点击“就试这套”采用并向已连接房间分享。默认点击其中英雄会触发预选并配置，锁定由玩家在客户端完成。
客户端选定英雄后仍优先显示“选人与配合”和当前需要做的事；更多配置可展开首屏下方“我的位置、出装、符文与加点”，或切到“出装 · 符文”：出门装、成装路线、完整符文、加点和召唤师技能均在侧栏查看，常用核心三件与符文以方案卡片展示用途、样本和选中状态，可直接比较、独立切换并收藏当前搭配；统计不表示它们互相绑定。顶部“装备 / 符文 / 加点”快速定位。
底部固定显示本局英雄的“替换符文”按钮，点击后直接覆盖一张可编辑页；调整和预览不会自动写入客户端。进入游戏自动指引可在底部开关。
“阵容详情”可调整位置与开黑成员，并展示我方覆盖、缺口、敌方公开已选和禁选。点击“展开助手”展开，点击“贴边选人”返回；设置中可关闭自动贴边。
选人时主界面和侧栏可以同时打开。侧栏默认宽度 440 Windows 逻辑像素、高度贴合客户端；在侧栏“设置”可选 400 / 440 / 480 / 520 / 600，空间不足时缩小到可用宽度。客户端位置的细微抖动不会反复改变侧栏尺寸；不会调整客户端或游戏窗口尺寸。
默认使用“单人推荐”，每张卡只推荐你的一位英雄。未确认位置时均衡展示各个空位置，也可先选择“我的位置”。
默认把客户端已选英雄自动放入阵容：保留手动位置，其次客户端明确分路，再按当前缓存的同版本分路样本或英雄位置机制参考暂排；位置冲突时依次安排其他空位。“暂排”不等于正式分路，可拖动交换。侧栏“设置”可以关闭自动暂排，不按列表顺序把你分到辅助。
组队时切换到“考虑全队”“只看我们”或“下路双人组”，再按下列方式安排位置。
1. 客户端已选英雄默认自动入队，无需拖入；不能在助手里删除或由推荐替换，更换请在客户端操作。手动加入的英雄也可锁定，推荐保留锁定英雄。
2. 进入选人前打开助手，可读取大厅公开预组队成员并匹配选人身份，默认自动标记“我们”。中途启动、接口不提供或隐藏身份时，可在侧栏“设置”的“补充队友 ID”每行填一个昵称#标签或公开数字 ID（最多四位）；无法匹配时直接点位置旁“我们 / 队友”。手动标记优先；不读取聊天或恢复隐藏身份，不向房间发送玩家 ID。
3. 拖动英雄头像到空位置立即换位；拖到已有英雄上交换位置。也可点“拖动换位”选择目标。
   “我们 / 队友”标记留在位置上。客户端选人中每约 2 秒读取公开信息；自动暂排不合适时可自己换位。
   拖动后的客户端英雄仍跟随该玩家后续换英雄，手动安排的位置不会被改回去。
4. 推荐范围：考虑全队（只推荐我们的位置，同时考虑队友已选）；只看我们（只考虑我们之间的配合）；
   下路双人组（只搭配下路与辅助，不受其他位置或归属标记影响）。锁定英雄在所有范围都保留。
   再选择稳定配合、娱乐实用或整活尝鲜，点击推荐。推荐计算在后台进行，条件变化后取消旧结果。
5. 点“英雄池”标记你们愿意玩的英雄；可用全部英雄、优先英雄池或只用英雄池。
   排除英雄和已公开禁选优先。仅用英雄池但某个位置无可选英雄时会提示调整条件。
6. 点“玩法与配置”看每个人补了什么、配合步骤及短板；点英雄头像看对应位置出装符文。
   两位朋友已选时，锁定他们并只标记你剩下的位置，也能推荐。候选卡突出推荐补位及其作用。
   方案详情底部固定“就试这套”；可连续替换多个未锁定推荐位置，替换失败会保留原方案。
   默认自动暂排已选英雄后即可分析配合；关闭自动暂排时，公开但未安排位置的英雄也不会重复推荐，可手动安排后分析。
7. 组合库收录 200 套下路搭配、68 套三人套路、127 条跨位置联动，可搜英雄、昵称、机制与风格。
   每套有配合步骤、短板和第三人参考。载入一对下路是手动参考，会替换这两个位置并保留其他位置。
   三人套路逐套整理实际位置、分工、步骤、行动窗口和短板；额外位置按分工补充，不把所有排列当作已整理组合。
   玩法来源包含 Riot 技能资料、Reddit、MOBAFire 与 BOTDIFF，可按来源及是否包含玩法配置筛选，并展开查看社区原文。人工建议未经过国服匹配胜率或版本强度验证。基础资料更新不自动验证组合库。
8. 客户端没有明确分配的位置会标为暂排参考；你可以随时换位，手动位置保留，不猜测隐藏英雄或玩家信息。
9. “清空英雄”保留客户端已选英雄、你们的位置归属、英雄池和公开禁选约束；归属可用单独按钮重置。
   搜索英雄会展示非常规位置的准确匹配。条件无解时保留说明与调整入口。

英雄图鉴、版本改动与排行榜
左侧“英雄图鉴”可按名称、称号、简称或拼音找英雄，再点P/Q/W/E/R查看技能。冷却、消耗和基础数值按技能等级排列；随英雄等级、R等级成长或特殊充能会另写规则。彗的主题子技能、厄斐琉斯的五种武器和多形态英雄可单独切换，避免把一种形态的冷却当成另一种。点“符文与出装”可查看同英雄配置，配置内的“技能与改动”可返回图鉴。
“近期改动”查看最近三版已收录的峡谷平衡变化，逐条显示改动前后值和加强、削弱或混合调整；主界面“版本改动”也可按版本和英雄／装备搜索。未收录不代表更早版本或其他模式没有改动。
主界面“各路排行”和选人侧栏“排行”可切换上、野、中、下、辅，以及全球／韩国、黄金以上／翡翠以上／钻石以上。榜单来自OP.GG公开聚合统计，显示样本和分析时间，不是国服统计。地区和段位只筛选排行榜，不会暗中切换已经选好的出装来源。
点击“刷新”获取对应榜单；断网或刷新失败保留同筛选的旧值。基础资料、技能描述、图标、版本说明和已缓存榜单均可离线查看。旧版会提示版本差异。图鉴是静态机制参考，冷却未计急速，资料范围不等于命中距离保证；不作为实时伤害、敌方冷却或斩杀线检测。

出装与符文
对应版本、英雄与位置的 OP.GG 全球排位常用配置用作匹配参考，不代表国服匹配胜率。
核心方案可切换；版本、获取时间和来源在配置下方显示。
当前基础资料为 16.20.1，包含 173 名英雄；各位置的统计版本分别显示，旧参考会单独说明。
每个位置可有多条核心路线、来源完整符文及加点，另有专用玩法配置；装备、完整符文页、加点及召唤师技能搭配分别显示自己的样本、胜率和选取率，缺失统计不会借用其他项目。
选人时在“对手”中手动确认公开已选英雄，再点击“刷新对某英雄的统计参考”，可比较该对手条件下的核心、符文和加点。刷新不会自动采用；地区、段位、版本与对手筛选须核对成功，失败保留原参考。没有此对手数据时明确显示普通同位置参考。
选择对手条件的配置后，来源筛选随成员准备、收藏和指引保存，界面可“恢复普通同位置来源”。这表示所选攻略的条件，不能证明新一局的实际对手。
召唤师技能中可展开“来源技能搭配”，选择来源中的合法技能对，再按需要调整 D/F 顺序；它不会向客户端自动更改技能。
从组合库或组合推荐打开配置时，自动带上适用的组合玩法；配置里可看补刀分工和搭档方案。
“配置玩法”可切回常规位置配置，或选择 AP、穿甲、保护等适用于这个英雄和位置的路线。
“推荐符文”可选择不同完整方案，标注用途、统计来源或人工整理；选中的方案用于复制和应用。
收藏及本局指引保留所选玩法和符文；源方案失效会提示重新核对，不把旧攻略装备当成当前最优。没有对应资料时使用机制基础方案。
开启更新偏好后，打开超过 24 小时的配置会尝试刷新，失败或断网仍使用本地资料。
人工搭配与机制提示单独维护；旧规则会标明待复核，基础资料更新不等于规则已重新验证。
自动升级装备会显示应购买的前置装备。鞋子可按对线提前购买，后续装备按实际局势调整。
点击“替换符文”才会写入，每次直接替换一张可编辑符文页，不要求空白页或空余名额。
优先复用上次写入的页，其次使用当前选中的可编辑页，再使用第一张可编辑页。没有可编辑页时才尝试新建。
原页名称与符文配置会被覆盖，不备份原方案；客户端只读预设页不可修改。游戏进行中不会写入符文。

完整准备文件（0.40.0）
在“开黑房间”点击“导出当前准备”，保存当前所选成员的装备计划、完整符文、召唤师技能、加点与已采用组合职责，无需创建房间。
自行把 JSON 文件私发给队友。接收方点击“打开队友准备”，先选择成员查看资料版本和原配置，再明确采用符文、加点与召唤师技能；装备单独参考。
文件是固定快照，不自动更新，不替换当前阵容，也不会直接写符文；写入仍需本人核对英雄并点击替换。昵称由文件提供，不能据此验证发送者身份。
文件不包含收藏备份、房间口令或客户端账号；收藏备份仍在“数据与连接”导入。

本局指引
默认是小型成装顺序卡；点击详情才展开购买组件、配合与更多内容。加点提示是独立小窗，可拖动到技能栏附近、单独叉掉，再从小卡“加点”或详情加点页恢复。关闭装备卡可以单独保留加点提示。
完整装备建议和少量备选按公开装备及自己标记的压力调整后续目标，保留组合核心、个人选择和已买装备；不自动买卖，不保证最优。下路第七件先等任务完成并明确确认。
