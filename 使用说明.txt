开黑搭子 · Rift Buddy
v0.54.0 使用指南

选好阵容，一起开黑。
为英雄联盟朋友开黑准备的 Windows 桌面助手：选阵容、配符文装备、共享方案，进入对局后查看需要的参考。

一、第一次使用
1. 运行安装程序，完成安装后打开“开黑搭子”，不需要安装开发工具。
2. 点击“打开英雄联盟”，优先通过 WeGame 启动；也可以先打开客户端，再打开助手。
3. 助手自动检测并连接客户端。未连接时，点击连接入口检查状态；若 Windows 请求授权，核对程序后确认。设置中可以指定启动路径或恢复默认。
4. 进入组队大厅或选人后查看侧边栏，主界面也可以同时使用。

二、先定阵容
五个位置展示公开的队伍选择。绿色范围表示参与“我们”的推荐，点击槽位角落可切换；已识别的开黑成员自动计入，手动位置保留。
默认两人及以上只考虑“我们”，只有一人时参考全队公开已选英雄，仍只更换自己的可选位置。队友位置未知时只参考英雄特征，不猜测其分路。
点击“给我推荐”或“开黑阵容”比较候选。点详情查看成员分工、成立条件与退出安排；契合分是机制规则参考，不是获胜概率。
“预选位置”用于匹配抢位置：从该路五位代表英雄中选择当前可用者，只预选、不配装，继续留在阵容推荐页。未锁定时可以换路。
点击候选中的本人英雄，一次采用方案、预选并准备配置；队友已选英雄只查看。最终锁定由你在游戏客户端确认。

三、准备自己的配置
选定实际英雄后进入“我的配置”。先核对完整装备顺序、符文、召唤师技能和加点；点击“调整”比较来源路线或自选内容。
组合有专用配置时优先使用该配置，其余使用常用来源参考；自己保存的有效修改继续保留。
默认保留客户端当前闪现 D/F 键位。只有你主动调整 D/F 或设置固定习惯时才更改。
英雄预选、符文、D/F、装备集各自显示结果。失败时先核对客户端，再重试失败步骤；助手不会替你锁定、禁用英雄、购买装备或升级技能。
调整和预览本身不写客户端，修改后点击应用。符文使用一张可编辑页，不修改系统预设页。

四、和队友用同一套方案
在支持的预组队大厅，助手默认通过中继连接同队房间；房间中的昵称使用公开游戏昵称。自定义房间或无法自动识别时，可以使用同一房间码和口令手动加入。
没有安装助手的队友仍可作为客户端公开组队成员参与阵容参考；只有运行助手并连入房间的人才能接收分享。
可以向房间提议候选、投票、采用方案及共享成员配置。收到提案不代表队友已实际选定英雄；每位玩家在自己的客户端确认。
共享内容可由房间成员和中继运营者看到，请只分享游戏准备资料。

五、进入对局以后
默认使用小型装备、加点和野区参考窗口，按需打开详情。各窗口可移动、调整大小、关闭和恢复；设置中可恢复默认布局。
装备页展示完整成装顺序和条件备选。野区页提供首轮与后续半区路线参考，可手动跟随、跳过或调整；不表示实际营地状态或最优路线。
助手不会检测敌人正在来抓人、敌方施法或真实技能冷却，不提供自动操作。
关闭主窗口后可从托盘重新打开，右键托盘选择退出。

六、资料和软件更新
排行榜、常用配置、海克斯参考由资料服务器每天两次检查。客户端下载后核验签名、哈希与内容；选人和对局期间暂存，空闲时启用，断网继续使用有效缓存。
排行榜保留来源地区、段位、样本和时间，不代表国服统计。人工配合玩法按各自复核记录维护，不因资料刷新自动成为“当前最优”。
“设置 → 软件更新”支持 GitHub 和 Gitee。下载校验完成后，明确点击“退出并安装”。
三个下载入口提供同版原始安装包。Gitee 手动下载需要全部分卷及同版 Merge.cmd，放在同一文件夹后合并；应用内更新会自动合并。

七、快捷键
Ctrl + Shift + Space：呼出或隐藏助手。
Ctrl + Shift + G：呼出或隐藏本局指引。
Ctrl + Shift + H：切换局内指引鼠标穿透。
快捷键被占用时，请使用托盘或桌面图标。
