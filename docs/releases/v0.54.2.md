# 开黑搭子 v0.54.2

选阵容、准备配置、连接队友各有自己的页面，让开黑前的操作更直接。

- 点击可选英雄头像即可预选并应用对应配置，参考分路与队友尚未锁定的预选不再阻挡；整套阵容无法采用时仍可选择单个英雄。默认保留闪现键位，锁定由玩家完成。
- 预选位置仅用于抢位置，保持在选阵容页；取消选人、匹配返回和下一局清理当局方案、操作结果与分享状态。
- 提议与投票直接显示，投票行和候选行统一尺寸、用背景色区分。点自己的英雄即可选择并配置，“采用整套方案”收进详情；选阵容页不再重复展示配置。
- 开黑房间是独立页面，支持重新连接当前组队。整合 PR #58 的单人自动房间与游戏昵称识别，并修复无名重名、同名误认队友、改名反复断开和投票丢失。
- 新增四套双人和四套三人玩法，组合库现有 204 套双人、88 套三人方案。配合有具体行动、条件、经济分工和退出时机，机制参考不代表胜率或最优配置。
