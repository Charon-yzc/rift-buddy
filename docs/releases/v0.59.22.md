# 0.59.22

海克斯侧栏将“选阵容”和“我的配置”分开。阵容页只比较本局公开备选池替换本人后的队伍，保留其余队友，不套用峡谷五路；按基础机制说明新增或减少的职责，未知备选池不推荐任意英雄。强化选择、已选联动与装备配置集中到“我的配置”，空白比较区默认折叠。换英雄在客户端操作后自动同步。

海克斯局内指引改为两个微窗：左上只放双方头像和公开装备总价值；右侧先显示较大的强化图标，再显示较小的装备图标，核心标边框，悬停查看简短说明。窗口可独立移动、隐藏，正文鼠标穿透。局外预览继续支持编辑，进出对局和断线时不自动弹出大窗口。

英雄手册增加173位英雄的同补丁强化选取记录，区分已观察、未观察、目录停用和未知。记录来自 Mayhem:Meta 公开汇总，随既有签名资料链更新；零记录不等于不能拿，完整英雄资格池和逐轮池尚未确认。

获取途径不再固定成四个按钮：按核对过的版本区分常规选择、K/DA额外强化及Command Line升阶重随等机制。尚无可靠自动接口的主秀只提供手动预览，新局清除；未知版本不沿用旧规则。

保留0.59.9至0.59.21的常用英雄缓存、稳定推荐、快速选人、直接曲线、海克斯三选一、条件玩法与数值修正。强化和装备配套路线按版本与效果复核；当前只有少数英雄的完整路线得到核实，不把独立榜单拼成“三套最热门组合”。

内置有效资料仍为16.20。16.21公开资源已能取得，但整套来源覆盖尚未通过校验，暂不替换有效资料。统计记录是来源观察，不是完整可选池、出现概率或本局胜率。

本版已同步 [GitHub](https://github.com/Legender134/rift-buddy/releases/tag/v0.59.22)、[Gitee](https://gitee.com/legender134/rift-buddy/releases/v0.59.22)和[下载页](https://room.riftbuddy.dpdns.org/downloads/)，完整安装包的SHA-256一致。0.59.8升级约1.58 MiB，0.58.7手动补丁约3.18 MiB；暂停保留进度，取消清理下载。
