# 野区规划怎么用

峡谷打野的独立小窗默认放在右下小地图上方，可以拖动顶部、点 × 单独关闭，从装备卡的“野区”恢复。先看第一行当前行动：生命不足四成、法力低于两成时优先比较补给；能量不足50时先等恢复；否则结合已学技能、英雄机制和你确认的条件比较清野与抓人。不会自动操作游戏。

开局小窗以两行显示实际营地顺序，不用逐个点营地。翠神使用画圈、回收与血蓝取舍的示例。皇子、盲僧提醒前三营后检查近处机会，梦魇、皎月侧重经验与 R 解锁，蔚比较清野与 Q 抓人。v0.48 新增猪妹、波比、千珏、阿木木、大树、蜘蛛、努努、扎克、男枪、佛耶戈、巨魔、莉莉娅的专属清野、抓人和恢复手法；其余未覆盖英雄继续明确标注通用参考。

蜘蛛、千珏、巨魔提供单体营地三营候选：红→蓝→蛙，或蓝→蛙→红；自己核对实际等级、基础技能和跨半区入口，再比较近处机会。没有窗口时后半行是可调整的补营示例，不能为了照顺序走完整圈而绕远。波比、大树、努努先连同半区三营，分别检查撞墙、W锁定接Q、雪球路线；猪妹、阿木木、莉莉娅侧重群怪经验和R，扎克同时看当前E等级射程，男枪与佛耶戈侧重清野及队友先控。没有“三营一定三级”或“六营必须刷完”的承诺。

开局之后仍显示路线。默认在3:30切到后续同半区轮转参考；这只是显示参考，不表示你已刷完首轮。小窗的“后续路线 / 首轮参考”可一键覆盖显示阶段，适合慢刷或提前回城；“红区 / 蓝区”切换锋喙鸟、石甲虫或三狼、魔沼蛙的具体顺序。BUFF 仅在实际可刷时纳入，翠神继续按画圈和成熟回收处理。这些选择只改变计划，不会标记营地已刷新、已刷完，也不会自动判断敌方位置；新局会清除本局计划。

公开本局能读取出生方时自动使用：蓝色方（左下基地）默认红起手，红色方（右上基地）默认蓝起手，这是下半区起手的示例，绝不是强制路线。点“⋯”可以改起手；读不到出生方时可自行补充。完整路线靠近哪条边路随出生方与起手变化；侵入、队友兵线、血蓝和回城都可以改变计划。助手不知道营地是否还在或是否已刷，不会用时间假装跟踪营地进度。

小窗可直接标记入侵、回城；“没机会”在详情里。它们由你确认实际情况：

- **被入侵**：取消旧抓人条件，先撤离；首屏切为另一半区恢复候选，入口已确认安全才走，不清楚就回城。结合英雄的撤退技能，放弃危险圆盾、粘液、印记或幽魂。
- **刚回城**：首屏切为当前计划半区的具体恢复候选，从安全入口检查营地实际还在；翠神按实际成熟情况回收。
- **没机会**：结束蹲等，显示当前半区补营候选，结合英雄技能沟通下一次控制。

这些标记 90 秒后失效，也可以点“恢复比较机会”。任何一次中断都会取消之前确认的兵线条件，恢复后不会沿用旧抓人结论。

想比较具体哪条路，点“⋯”在详情选上、中、下路，再确认敌方压出、队友能跟、有可靠控制、进退安全。条件最长保留 90 秒；目标退回、队友回城或局势改变就应清除或重选。只有本局匹配、常规峡谷队列、健康与基础技能可读且学齐、版本参考一致时才提出抓人候选。**已学 R 不代表 R 已就绪**；资源阈值只是保守提醒，不保证够打一套。读不到法力／能量时明确保留自行核对；助手仍需你在游戏内核对技能、法力、惩戒和撤离方向。详情继续提供当前组合的本人职责、资源与反蹲取舍。

当前依据为 16.20 静态技能资料和机制核对，没有国服真实清野耗时、胜率或最优路线证据。营地顺序是结合技能与己方地图地理的编辑候选，没有复制网页路线图、营地经验或清野时刻。Mobalytics 攻略没有可确认的16.20内容修订时间，部分仍有旧版表述，只借机制及刷／抓取舍；不继承“必定击杀”“独自资源必胜”等结论。
