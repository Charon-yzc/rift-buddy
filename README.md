**打开助手，跟着游戏走。** 客户端连接、组队识别、开黑人数同步和阵容推荐默认自动进行。和朋友进入游戏组队大厅后，自动连接同一助手房间；进入选人后，贴边侧栏把阵容、提议和配置放在手边。

你主要做两件事：**挑自己想玩的英雄，在客户端确认锁定。** 点击推荐里的英雄头像时，对应英雄与整套配置一起准备，不用再逐个找符文、召唤师技能和商店装备集。支持单人参考与二至五人开黑，主界面和侧栏可以同时使用。

## 三步开始

1. **打开助手和英雄联盟。** 自动检测并连接客户端。
2. **和朋友进入游戏组队大厅。** 自动进同一开黑房间、同步人数与分路、推荐阵容，无需建房或填邀请码。
3. **点推荐中自己的英雄。** 英雄预选、符文、D/F 和装备集一起备好，最后在客户端确认锁定。

想换配置，在“我的配置”点“一键切换”；想和朋友商量，直接提议阵容、投票。其余说明和数值悬停或展开再看。[简短使用指南](使用说明.txt)。

## 人数、分路和推荐，跟着这局走

进入选人时，按游戏组队人数自动圈出“我们”；有预选分路时优先同步对应位置，没有时按顺序安排。队友选英雄或换位时自动让位，推荐人数保持不变；只有你手动点亮或熄灭位置圆点，才改变推荐人数。

- **“参考预选”默认关闭；开启后，公开预选英雄也参与推荐。确认锁定的英雄始终参与。** 公开禁选、锁定结果或分路变化后自动更新推荐，想多看几套时再点“换一批”。
- 保留已选队友、已锁英雄和手动位置，头像与分路图标集中呈现，详细依据按需展开。
- **预选分路**用于抢位置，**预选英雄**用于表达想玩哪个英雄；两者都准备完整配置、留在选阵容页，确认锁定后才自动打开配置页。也可随时手动打开“我的配置”。预选头像右上角的 × 可取消英雄，保留分路和人数；选择面板里的“取消”只关闭面板。
- 顶部队伍栏只展示英雄，空位使用人物图标。选择英雄统一从预选入口、候选或队友提议进入。

## 点哪个英雄，就准备哪套配置

点击候选或提议阵容中自己要玩的英雄，直接在客户端预选，同时准备该方案的**符文、D/F 召唤师技能和商店装备集**，并展示装备顺序与加点参考。组合有专用配置时优先使用，没有时使用默认常用配置。**默认保留闪现键位，最终锁定由你在客户端确认。** 已锁英雄不会被替换，仍可调整它在阵容中的位置。

配置页先展示当前配置和两套备选，点“一键切换”即可整套切换，不用逐项调整。分路下拉框可浏览其他位置的配置，浏览不写入客户端，点击应用才生效。装备与符文图标随窗口宽度均匀分布，鼠标悬停再看具体说明、数值和价格；加点以“主升／开局”区分。

## 推荐更广，评分可以看明白

结合成员衔接、分路可行性、共同战术、伤害来源与行动条件计算契合分。消耗、保护、持续输出、开团与边带牵制都纳入考虑；同一局的候选顺序稳定，不同局在适合的方案中探索变化，“换一批”减少重复英雄。数字悬停可看每项得分，展开查看配合条件。**这是机制规则分，不是预测胜率。** [评分与调研依据](docs/recommendation-scoring.md)。

## 同一个游戏组队，自动进同一个助手房间

默认开启自动组队房间。朋友都开着助手、进入同一游戏预组队大厅后，按当前游戏组队自动加入同一助手房间，**不用各自建房，也不用手动输入邀请码**。昵称跟随游戏，房间页可核对在线成员；断线时可重新连接当前组队，也可手动加入。

向队友提议喜欢的阵容、投票，再点击自己的英雄准备配置。提议只展示本次推荐实际参考的成员；左上角昵称摘要可悬停查看全部提议者。锁定后仍可重新推荐、提议和投票，自己的英雄不会被更换。可以支持多套阵容，每人每套最多一票，再点撤回；采用后查看各成员的开局分工、配合条件和转变打法的时机。

没有安装助手的朋友仍可作为公开队友参与阵容参考；房间在线成员与游戏组队成员分别显示。

## 紧凑侧栏，配色自己选

圆角方框与大头像随窗口宽度排列，取消重复的英雄名和分路文字。底部圆点显示客户端状态：绿色已连接、红色未连接，连接中显示暖黄色；未连接时点一下圆点即可尝试连接。

提供 **18 套配色**，包括 9 套客户端灵感配色。在“设置 → 窗口与显示 → 配色”或“开黑房间”旁的“更多 → 配色”中切换，主界面与侧栏即时同步，选择自动保存。

英雄图鉴提供技能数值、冷却、消耗与近期改动；五路排行保留地区、段位、样本和统计时间，选人时也能查。

进入对局后，按需使用小型装备、加点和野区路线参考窗口。窗口可以移动、调整大小、收起或关闭，设置中可恢复默认布局。

## 更新与玩家资料

有适用增量时，软件更新优先下载小补丁：不仅复用相同文件，也复用程序大文件内部未变化的数据。只改少量代码时无需重下整个运行库；缺少增量、本机文件被修改或校验失败时使用完整包。**0.55.1 及更早版本首次升级仍需完整包**。

安装器先拼齐并校验全部新版文件，再停止旧程序、卸载旧程序文件、安装新版；收藏、准备配置和配色保留，升级失败尝试恢复旧程序。[更新与安装说明](docs/incremental-updates.md)。普通使用不需要开发工具。
