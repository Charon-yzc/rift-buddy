# 预选位置与单人阵容推荐

预选位置用于向队友表达分路意向。点击分路只发送一次英雄预选，不锁定、不应用符文、召唤师技能或装备集，也不切换到配置页。点击实际候选英雄才预选并配置；玩家在客户端锁定后进入配置页。

## 占位英雄如何选择

使用 OP.GG 同版本、全球黄金以上的 `role_rate`：该英雄在指定位置出现的比例。比例越高，越不容易被理解成其他位置。胜率和强度不参与这个排序。

- 至少 1,000 场该位置样本、该路选取率至少 1%、位置占比至少 85%。
- 先按位置占比降序，同值按样本量降序，再按英雄 ID 排序。
- 每路取五位；依次跳过本局未拥有、禁用、已禁选或被其他玩家选走的英雄。五位均不可用时提示直接选择其他英雄。
- 优先使用已校验的同版本排行榜，不额外发起网络请求。资料不足或离线缺失时使用下面的已核对名单。

## 一个人也能推荐阵容

只有本人一个位置属于“我们”时，“开黑阵容”参考全队已经公开的英雄，只改变本人未锁定的位置。占位英雄不固定候选；队友选择和明确的位置安排保留。契合度按候选英雄与已知队友计算；队友尚未选人时保留“信息不足”，不编造其余四位英雄或配合分。

主界面和侧边栏使用同一规则。完成锁定后保留本人的英雄，只分析现有阵容。
