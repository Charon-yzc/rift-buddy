# 英雄图鉴、版本改动与各路排行

从主界面左侧打开“英雄图鉴”，搜索名字、称号、简称或拼音，点击英雄即可查阅。技能图标和文本随应用提供，断网可用。

技能页先显示所选技能的冷却、消耗、数值和作用。斜线数值按技能等级排列；随英雄等级或大招等级成长的内容另行说明。生命消耗区分固定点数、当前生命比例和最大生命比例，持续耗蓝按每秒标注。充能恢复与再次施放间隔分开，不能把零冷却的包装技能理解为无限施放。彗的九个子技能、厄斐琉斯的五种武器，以及豹女、蜘蛛、杰斯、纳尔、雷克塞、卡尔玛、克烈和凯隐等不同形态可分别切换。自身强化和被动触发不显示没有实际意义的引擎射程。冷却未计算技能急速，资料范围也不保证目标在该距离一定命中。

“近期改动”显示最近三版已收录的召唤师峡谷平衡变化，逐项比较前后值，并区分加强、削弱和混合调整。点击“官方说明”查看原文；从独立“版本改动”页的英雄名称也可直接进入图鉴。没有条目只表示最近收录的三版没有此英雄的峡谷改动，不能推断更早版本或其他模式没有改动。

图鉴的“符文与出装”打开对应英雄的现有配置；配置中的“技能与改动”返回图鉴。查阅资料、切换技能或排行筛选不会写入客户端。预选和配置仍需本人明确点击；锁定由玩家完成。

“各路排行”提供上／野／中／下／辅，支持全球／韩国及黄金以上／翡翠以上／钻石以上六组筛选，可按梯级、胜率、登场率或样本查看。数据来自 OP.GG 聚合统计，显示本组筛选的版本、样本、分析和获取时间。原始来源的 T0 为最高梯级；缺少梯级或名次时保留缺失，不补造。它不是国服榜单，也不能把某位置统计当成组合胜率。

选人侧栏顶部“排行”可直接使用这些榜单。查看和滚动榜单时，顶部保留本人下一步、五位置当前队伍和返回配合的入口；收到的新队友方案先显示在榜单上方。点击本人可选英雄沿用预选与配置功能，成功后回到全队；点已选队友英雄查看配置。榜单的地区和段位只改变榜单，不会改变当前配置来源。刷新失败保留同组缓存，不用另一地区、段位或旧版本的数据填充。图鉴、排行和版本页共用“字号与指引”中的文字大小设置。

技能资料主要依据腾讯官方详情，冷却和消耗等级顺序取同版 Riot Data Dragon，特殊形态结合同版客户端资料整理。宝石每层治疗、女枪弹幕总伤害、塔姆与狗熊依属性变化的公式等按实际字段交叉核对，不能把示例属性下的结果写成固定能力。更新游戏基础资料不会自动证明技能语义已复核；若图鉴版本落后会保留旧版并提示。厄斐琉斯断魄伤害、克烈手枪充能、凯隐刺客W伤害的客户端说明与其他内部字段之间，仍缺少真实游戏结算证据，技能页分别保留该限制。

强化数值会列出中间技能等级，例如莉莉娅W中心伤害为240/300/360/420/480，索拉卡R低血量基础治疗为225/375/525。派克Q可分别看秒放与蓄力；韦鲁斯、泽拉斯、蔚和扎克也区分蓄力前后距离。瞄准线、圆形指示和内部距离参数不总相同，页面会标明各自含义及尚未核实的实际边界，不把初始距离当作满蓄力射程。

维护时可执行 `pnpm sync-rankings` 重新收集六组统计。`pnpm sync-abilities` 收集技能及图标；特殊技能整理按版本设置检查，换版本需复核，不能只改版本号。两者只读取公开资料，不需要游戏账户或凭据。
