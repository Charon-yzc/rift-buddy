# 0.58.7 · 排位参考与紧凑选人

- **排位也能一起配。** 单双排、灵活排位参考客户端公开的双方英雄和分路对手，随着选人更新建议；锁定后查看阵容分时统计参考。契合分属于机制规则分，曲线不代表本局预测胜率。
- **推荐和资料一起更新。** 新增有来源的跨位置双人方案，英雄池连续勾选不再跳回顶部；签名整套资料在选人、对局时暂存，回大厅后启用。机制源变化会要求相关组合重新复核，不拿旧数据冒充新版本。
- **配置更稳。** 队伍聊天简报默认关闭，设置开启后才发送；换局、改配置或中途关闭开关会取消迟到消息。关闭或切换配置面板不会改变点击时的应用内容。一级技能点已用完后不再高亮首点建议。
- **页面更清楚。** 战绩、实时对局修复后台刷新和小队显示；深浅配色下的装备悬停、详情页签、统计小字和等级角标保持可读。
- **更新只留需要的文件。** 成功升级后自动清理更新缓存和中断残留；有效待安装包、暂停进度、个人配置和收藏保留。应用内不会重复安装同版或降级。

**使用只需三步：** 打开助手和客户端；和朋友进入同一游戏组队大厅；点推荐里自己的英雄备好配置，在客户端确认锁定。想商量就提议、投票，更多说明悬停或展开再看。

从 **0.57.3** 升级提供约 **3 MB** 增量；完整安装包约 **148 MB**。只有本机基础文件匹配时才使用增量，校验失败保留完整包回退。暂停可续传，取消会清理下载；升级保留个人设置和收藏。

客户端、符文、聊天和回放验收使用隔离模拟；真实国服接口兼容仍需实际使用核验。个人战绩保留在本机运行内存，不上传服务器。
