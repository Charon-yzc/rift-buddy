# 本机小样本胜率试验

该工具复用现有LCU和固定SGP战绩通道，在本机内存中构造国服小样本。它只用于研究可行性，不接入产品胜率显示，不上传训练数据，不保存原始战绩、玩家标识或逐局特征。

## 固定范围

默认只取召唤师峡谷单双排420，最多300场有效去重目标对局。起点为本人近期对局中实际返回的公开玩家，最多8个种子玩家；再读取最多240名玩家的近期摘要，每人至多100条，供20场历史窗口使用。单页至多20场，本人和种子玩家最多100条，补历史阶段每人最多40条；只在本机按真实queue ID过滤，避免后台队列过滤失效时混用分页游标。目标集合先冻结，补历史不会改变测试边界。样本来自有限关系网络，不能代表国服全部玩家与段位。

每轮最多420次服务操作、15分钟，历史数据经裁剪后不超过24 MB；现有战绩服务仍有自己的并发与缓存上限。最多读取120场完整时间线，同一时间只处理一份，并给时间线保留请求预算。连续3次读取失败或出现限流时停止该轮，保留已获取数据的内存评测。来源拒绝、队列过滤不可用、请求过频或数据不完整均计数，不切换队列补足目标。

补历史结束后按剩余请求预算确定时间线数量，在完整目标时间范围内等距取样，包含首尾，不只读取最早的对局。每条时间线先重新加载其原玩家、原分页并确认目标仍存在，再立即读取时间线，避免240名历史玩家查询淘汰服务中仅保留48份的旧句柄；这两次操作都计入420次上限。真正的账号、会话或大区变化仍会终止本轮。

## 特征与防泄漏

赛前比较固定胜率、仅阵容逻辑回归、阵容加玩家历史逻辑回归。十位玩家的历史仅保留目标局开始前已结束的同队列有效比赛，排除目标局、重复、未知胜负和跨开局重叠对局，按结束前可用的最近20场构造样本覆盖、收缩胜率、英雄经验、KDA、分均补刀/伤害/金币/视野/治疗。缺失带独立标记，不解释为实测零。

历史窗口被接口最近记录上限截断时，样本数照实记录。当前段位、当前熟练度和从目标局赛后统计推断的分路不作为历史时刻输入。首轮不加入分路与英雄协同项。

局内模型只用每5分钟的时间、双方平均等级差、补刀差及事件重建的击杀/死亡/助攻差。只读截至快照时刻的事件；十人帧、事件覆盖、参与者与助攻身份必须可核验。不使用历史精确金币、XP、伤害、坐标或当前实时不可等价取得的字段，不使用最终统计反填早期状态。结束时刻快照排除。

按整场开局时间排序，最早70%训练、中间15%独立sigmoid校准、最后15%最终测试。同开局时间不跨集合；跨下一集合边界尚未结束的训练或校准对局剔除，确保其标签当时已可用。时间线继承赛前目标集合的划分。训练类别不足时返回不可评测；校准集只有一类时不拟合校准器，明确标记`evaluated-without-calibration`，仅保留未校准输出的独立测试指标。测试单类时AUC为null，不能据此证明区分能力。

逻辑回归固定迭代160次、L2为0.1、步长0.15，标准化只拟合训练集。超参数在真实试验之前固定，不用测试集选优。多快照训练和评测按每场等权；局内另报5分钟时间段。小样本分箱、AUC与准确率仅为探索性结果，不能称为已验证的国服生产概率。

## 执行

```powershell
node --test tests/win-probability-local.test.mjs tests/win-probability-offline.test.mjs
node scripts/win-probability/local-run.mjs --read-client --helper
# 单独的匹配对照，不与420合并
node scripts/win-probability/local-run.mjs --read-client --helper --queue 430
```

`--read-client`是显式真实读取开关；`--helper`使用已打包连接进程与正常Windows权限确认。客户端以管理员运行时在系统确认中选择“是”。退出后停止本次连接进程，删除本次临时握手文件。没有符文、装备集、聊天、选人或回放写入。

本地结果位于`.local/win-probability/local-experiment-420-results.json`（匹配对照为`local-experiment-430-results.json`），只含预算、覆盖计数、聚合指标与模型指纹，不含逐局样本、玩家名、身份、凭据或可加载模型。原始记录和训练矩阵随进程结束释放。采集结束后复跑需要重新只读获取，不能从磁盘恢复原始个人战绩。

## 本机实测与后续复跑

本机国服LCU能返回本人战绩，现有SGP接口也曾返回完整十人时间线；接口状态会变化，摘要或详情返回HTTP 500时无法完成计划采样。认证令牌可取得不代表业务请求一定可用。不能把单次来源故障写成“本机不支持完整时间线”，也不能把前一次成功当成当前可用证明。

本轮简单模型已经在实际取得的小批目标局上完成拟合与时间留出评测。样本不足时未执行校准，模型未显示可依赖的提升；详细个人样本量、覆盖与指标仅保留在上述本地忽略目录和本机会话，不写入公开仓库。本轮局内训练受来源故障阻塞。430匹配对照另行读取和保存，没有加入420成绩。

下一次复跑应先确认SGP摘要与时间线恢复，再扩充目标对局和十人赛前历史覆盖。模型超参数、划分和校准规则维持固定，不为改善这次小样本成绩而移动测试边界或挑选胜负。

## 工程验证

23项本机试验针对测试与18项既有离线测试通过，包含300/239目标的时间线分区、真实服务的48句柄淘汰、真实会话变更停止、独立系统临时目录和分页响应跨截止时间保留聚合结果的回归。原提交全量`pnpm test`为2,836通过、1跳过、0失败；`pnpm check`通过（723个JavaScript文件），修订后的完整验收另见PR记录。研究脚本另外执行语法检查。个人汇总报告经字段检查，没有玩家身份、原始对局或逐局特征。

Windows本地打包、包内容一致性检查和9阶段隔离应用冒烟通过，研究脚本和本地结果未进入包内，冒烟真实客户端写入为0。打包结果保留本机，没有发布安装包。
