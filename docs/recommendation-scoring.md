# 开黑推荐与契合分

契合分是可解释的机制规则评分，不是组合胜率或“最优阵容”。推荐保留真实锁定结果、公开禁选、玩家英雄池及手动分路；不读取隐藏玩家数据。

## 预选与锁定

“参考预选”位于风格旁，默认关闭并保存选择。关闭时预选只用于展示；开启时，公开的未锁定英雄也作为当前推荐条件。重复或无法可靠对应玩家的预选不强行绑定。锁定英雄始终参与；本人的锁定英雄即使没有点亮“我们”也保留为依据，不能被替换。关闭自动安排且本人分路未知时，会先提示确认分路，不能默默漏掉本人继续推荐。

预选分路和点击英雄都会准备完整配置，停留在阵容页。客户端确认锁定后自动转到配置；不会重复写入或自动锁定。配置切换和符文写入由玩家明确点击触发。

成员衔接检查控制与跟进、消耗与消耗、保护与持续输出、短周期与持续伤害等关系。共同战术评估开团、反打保护、持续输出、消耗或边带牵制的实际条件。行动条件来自当前技能、成长、装备或大招门槛，不能把需要等待的方案描述为立即可用。

数字悬停展示当次每项实际得分。完整度、取整与选人冲突的调整单独列出，显示项目相加等于最终整数。详细面板保留缺口与执行条件。单人参考仍结合公开队友，不能将个人分误称为五人完整阵容分。

## 覆盖与随机性

候选包含人工整理方案、当前技能配合、职能组合和完整阵容采样。每个合规英雄与战术保留最佳候选，避免只在少数高分英雄的小变体里搜索。选取时惩罚重复英雄与相似战术，保留人工方案和创意方案的发现位置。

以公开游戏 ID 为种子，同局相同输入和分页顺序稳定；不同局改变候选采样和相近分数的排序。随机扰动只用于排序，不改变显示分数。无游戏 ID 时使用当前窗口会话种子。禁选、不可选英雄与锁定约束优先，随机性不能突破这些条件。

本轮同条件对照：中/下/辅三人、常规分路、10 个游戏种子、每局前 6 套，旧版出现 16 个不同英雄，新版 39 个；新版亚索出现 2 次。这是固定样本的覆盖检查，不是所有阵容都更强的证明。

## 调研依据与取舍

- [Mobalytics：阵容与团战](https://mobalytics.gg/lol/guides/everything-you-need-to-know-about-team-comps-and-teamfighting)：参考其消耗、保护、边带等战术分类；不把控制数量当作唯一目标。
- [LoLTheory 产品方法](https://blog.loltheory.gg/what-is-loltheory/)：参考队伍、对手与个人偏好的区分。其模型与效果陈述属于产品方自述，本项目没有照搬其胜率。
- [DraftRec 论文](https://arxiv.org/abs/2204.12750)：参考团队协同与个人偏好共同建模的思路。本项目没有对应训练数据或校准模型，因此保留透明规则评分。

实现入口：`src/core/composition-fit.mjs`、`recommend.mjs`、`recommendation-diversity.mjs`。回归检查包括固定成员、英雄池与禁选、同局稳定分页、跨局差异和精确分解。
