# 野区规划怎么用

峡谷打野的独立小窗默认放在右下小地图上方，可以拖动顶部、点 × 单独关闭，从装备卡的“野区”恢复。先看第一行当前行动：生命不足四成时优先补给；否则结合已学技能、英雄机制和你确认的条件比较清野与抓人。不会自动操作游戏。

开局小窗以两行显示完整六营示例，不用逐个点营地。翠神使用画圈、回收与血蓝取舍的示例。皇子、盲僧提醒前三营后检查近处机会，没机会继续后三营；梦魇、皎月侧重经验与 R 解锁。蔚同时比较清野与 Q 抓人，R 学会后提示锁定与跟进。其他英雄明确显示通用参考，尚无专属手法。

公开本局能读取出生方时自动使用：蓝色方（左下基地）默认红起手，红色方（右上基地）默认蓝起手，这是下半区起手的示例，绝不是强制路线。点“⋯”可以改起手；读不到出生方时可自行补充。完整路线靠近哪条边路随出生方与起手变化；侵入、队友兵线、血蓝和回城都可以改变计划。助手不知道营地是否还在或是否已刷，不会用时间假装跟踪营地进度。

小窗的三个按钮由你确认实际情况：

- **被入侵**：取消旧抓人条件，先撤离到队友能接应的一侧；安全入口不清楚就比较回城。
- **刚回城**：从安全入口重新检查实际营地，连接同半区；翠神按实际成熟情况回收。
- **没机会**：结束蹲等，转同侧安全营地，沟通下一次控制。

这些标记 90 秒后失效，也可以点“恢复比较机会”。任何一次中断都会取消之前确认的兵线条件，恢复后不会沿用旧抓人结论。

想比较具体哪条路，点“⋯”在详情选上、中、下路，再确认敌方压出、队友能跟、有可靠控制、进退安全。条件最长保留 90 秒；目标退回、队友回城或局势改变就应清除或重选。只有本局匹配、常规峡谷队列、健康与基础技能可读且学齐、版本参考一致时才提出抓人候选。**已学 R 不代表 R 已就绪**；助手仍需你在游戏内核对技能、法力、惩戒和撤离方向。详情继续提供当前组合的本人职责、资源与反蹲取舍。

当前依据为 16.20 静态技能资料和机制核对，没有国服真实清野耗时、胜率或最优路线证据。参考 Mobalytics 的英雄阶段取舍，攻略没有可确认的 16.20 内容修订时间，部分仍有旧版表述，未把它们当作本版数值依据，也未复制路线图。例子不是对所有对局的保证。
