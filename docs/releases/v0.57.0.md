# 0.57.0 · 开黑推荐与对局参考

- “参考预选”默认关闭，开启后预选英雄参与阵容推荐；锁定英雄始终参与，不能被替换。
- 点击英雄准备对应整套符文、召唤师技能和商店装备集。预选时留在阵容页，确认锁定后打开配置，也可手动查看。
- 推荐覆盖消耗、保护、持续输出和边带等打法；跨局探索变化，契合分悬停查看分项，分数不是预测胜率。
- 提议只显示本次推荐参考的成员；昵称摘要和完整名单、投票与操作结果集中呈现。房间成员列表和连接操作更紧凑。
- 新增可选的 Akari 战绩分析和实时对局：公开玩家查询、组合筛选、单局复盘、玩家卡和历史阵容演练。
- 战绩、备注和筛选预设只在本机有界运行内存保留，不进入项目服务器或备份；回放下载和观看需要明确点击。
- 支持后续增量更新；首次从 0.55.1 及更早版本升级使用完整包。安装先验证新文件、停止旧程序，再替换程序文件，保留玩家资料。

国服真实战绩接口和回放兼容尚未实机验证。自动验收使用隔离状态，模拟客户端、符文与回放操作。
