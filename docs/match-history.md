# 战绩查询

本模块移植并适配本机提供的 League Akari 1.5.1 战绩相关源码，来源提交 `60f1584c3d3e45b2bb183aefcc615d35d7cffcb8`。版权声明见 `THIRD_PARTY_NOTICES.md`。

## 使用

1. 登录英雄联盟客户端，在开黑搭子完成连接；若客户端权限更高，点击连接并完成 Windows 授权。
2. 左侧选择“战绩查询”，点击“我的战绩”，或输入玩家的完整 `游戏名字#标签`。只输入名字时尝试 Riot Client 名字搜索，并从结果中选择玩家。
3. 默认自动选择游戏后台；同区后台不可用时回退到本机客户端。可明确选择客户端或游戏后台，以及目标大区。跨区能力依赖具体游戏后台接口及认证，失败不会使用本区数据冒充结果。
4. 上一页/下一页每页 20 局，批量加载每轮至多 20 局，单个标签最多保留 500 局；达到上限后不继续请求。筛选只作用于该标签已加载的数据，顶部显示实际样本范围。
5. 展开对局可查看概览、详细数据、符文/强化、装备购买/技能加点、击杀/目标事件和逐分钟时间线。购买、加点、完整属性和阵亡伤害仅在数据源实际返回时展示，LCU 常缺少其中部分事件。时间线同时展示对局结束后的目标统计；满足公开数据条件时展示带说明的打野分钟位置参考。
6. 排位与熟练度在当前大区按需读取，跨区未提供。点击玩家名字或近期共同对局可打开另一个标签，最多 10 个。
7. 回放检查、下载和观看都由用户点击发起；只允许当前大区已加载对局，下载和播放只在大厅或结算阶段。首次检查没有元数据时，按 Akari 的接口流程尝试初始化；过期、版本不兼容或接口拒绝会显示错误。

## 数据口径

- 缺失统计显示“未读取”，已确认的 0 保留为 0。LCU 没有的分路、护盾、强化或时间线字段不从其他数据猜测。
- 近期统计过滤人机/非匹配对局、重开和中止，只统计已经确认本人参与且胜负可知的局。筛选后样本数会单独说明。
- 斗魂竞技场使用已返回的小队数量和名次，将前半小队视为胜利；实际名次同时保留显示。
- 依赖完整队伍的占比和评分只在逐队人数核验通过后计算，包括 1750 队列的三人小队。未补齐的摘要不冒充完整队伍。
- Akari 参考评分使用其击杀参与、伤害、承伤、经济、治疗、视野、补刀和胜率权重，总分 17；资料不足时显示“资料不足”。这不是官方评分，也不是最优阵容或获胜概率。
- 共同对局仅说明已加载对局里同队/对手的重复出现，不等于预组队关系。
- 打野路线使用已结束对局的分钟位置和击杀参与事件。区域权重、营地距离参考沿用 Akari；一分钟位置接近某营地不能证明实际首开，不提供游戏中的追踪。

## 实现与边界

`src/core/match-history/` 负责清洗与分析；`services/match-history.mjs` 负责查询对象、会话检查和缓存；`services/match-history-{routes,sgp,riot}.mjs` 分别限制 LCU 路由、固定 SGP 地址和 Riot Client 回环名字搜索。页面状态在独立控制器中，不写入收藏、偏好或备份。

LCU/RC Basic 凭据只发送到本机回环。后台战绩使用 entitlements access token，玩家大区资料使用 league-session token；凭据不通过渲染层、不写入日志、不发送到项目服务器。固定后台请求不跟随重定向，单次响应上限 8 MB；本机 LCU 保留 2 MB 上限；授权管道为战绩单独设置 4 MB 字符上限，其他操作仍是原上限。

每个服务最多同时执行 3 个战绩操作，队列最多 12 个；单页最多 100 局；服务缓存最多 128 条，玩家会话最多 12 个。账号或连接身份变化后旧句柄失效；页面请求用世代号防止旧结果覆盖新查询。所有自动化测试中的客户端和回放写入均为模拟。

同区列表、详情或时间线后台失败时可退回 LCU，并说明减少的字段；跨区不回退。并发缓存按来源合并，清理直接使旧查询失效，无需等待查询队列。窗口缩窄时近期统计改为可展开区，保留常用英雄及共同对局入口。

SGP 为未公开且会变化的接口。地址参考固定的 Akari 配置，不宣称永久有效或所有大区互通。网络加速器可能只代理客户端而不代理助手的 SGP 请求；可在同区切换为“客户端”确认数据源差异。

## 验证

执行 `pnpm test`、`pnpm check`，再打包并运行 `node scripts/inspect-package.mjs --verify-current`、`node scripts/smoke-package-lifecycle.mjs` 与 `node scripts/smoke-package-match-history.mjs`。战绩冒烟使用隔离设置和模拟 loopback 数据，覆盖页面查询、分页、筛选、详情、符文、出装、时间线、回放点击和断线错误，以及桌面/小屏截图。

真实国服验收仍需与已登录客户端逐项核对本人、战绩、KDA、装备、分页、回放与后台大区支持；模拟与打包通过不能替代该项验证。
