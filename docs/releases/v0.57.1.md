# 0.57.1 · 当前装备方案优先显示

源码与本地安装包版本；尚未公开发布，公开下载仍为 0.57.0。

- 将装备集从全局目录改为当前英雄的专用目录，并限制对应地图，避免其他英雄和地图的配装混入。
- 当前方案使用自定义优先级，最近成功应用的方案排在本工具旧方案之前；连续切换分路时按点击顺序写入。
- 新文件写入并读回确认后，只迁移同名、身份匹配的本工具旧全局文件。其他工具、玩家配装及发生并发修改的文件保留。
- 保留一键配置与符文明确点击要求，不自动锁定英雄。装备在下局读取，当前对局是否刷新以游戏商店为准。
- 从 0.57.0 升级的本地增量包为 89.5 MiB，完整包约 141 MiB，下载量减少约 36.5%；基线不完整或校验失败时回退完整包。当前机制按文件差量，程序主文件的版本元数据变化仍会带入整个主文件，因此本轮增量尚非极小补丁。

技术依据为 Riot 旧开发者文档的 [CommunityDragon 存档](https://github.com/CommunityDragon/HexDocs/blob/master/lol/misc/itemsets.md)：磁盘目录控制英雄范围，custom 在 global 之前，priority 和 sortrank 控制优先排序，map 控制地图。该说明是历史协议资料；当前国服游戏商店实际默认选中行为仍需玩家下一局验证，隔离测试不冒充实机验证。
