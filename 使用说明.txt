开黑搭子 v0.9.2 · 个人英雄联盟助手

双击“开黑搭子.exe”。请保留整个文件夹，不要单独移动 exe。
Ctrl + Shift + Space 呼出 / 隐藏助手，Ctrl + Shift + G 呼出 / 隐藏本局指引。
Ctrl + Shift + H 在游戏中切换指引的鼠标穿透 / 可交互状态，也可从托盘切换。
快捷键被占用时从托盘或桌面图标打开。关闭主窗口后仍在托盘运行，右键托盘可退出。

三人选人
1. 把已选英雄放入阵容，选中后默认锁定，推荐不会替换锁定英雄。
2. 点“我们 / 队友”标记你们本局负责的位置；五个位置都支持。
3. 拖动英雄头像到空位置立即换位；拖到已有英雄上交换位置。也可点“拖动换位”选择目标。
   “我们 / 队友”标记留在位置上。客户端选人中每约 2 秒读取公开信息，不明确的位置拖到空位安排。
   拖动后的客户端英雄仍跟随该玩家后续换英雄，手动安排的位置不会被改回去。
4. 推荐范围：考虑全队（只推荐我们的位置，同时考虑队友已选）；只看我们（只考虑我们之间的配合）；
   下路双人组（只搭配下路与辅助，不受其他位置或归属标记影响）。锁定英雄在所有范围都保留。
   再选择稳定配合、娱乐实用或整活尝鲜，点击推荐。推荐计算在后台进行，条件变化后取消旧结果。
5. 点“英雄池”标记你们愿意玩的英雄；可用全部英雄、优先英雄池或只用英雄池。
   排除英雄和已公开禁选优先。仅用英雄池但某个位置无可选英雄时会提示调整条件。
6. 点“玩法与配置”看每个人补了什么、配合步骤及短板；点英雄头像看对应位置出装符文。
   两位朋友已选时，锁定他们并只标记你剩下的位置，也能推荐。候选卡突出推荐补位及其作用。
   方案详情底部固定“就试这套”；可连续替换多个未锁定推荐位置，替换失败会保留原方案。
   公开但未安排位置的英雄也不会重复推荐；拖入位置后才分析它的具体配合。
7. 组合库收录 155 套下路搭配、50 套三人套路、127 条跨位置联动，可搜英雄、昵称、机制与风格。
   每套有配合步骤、短板和第三人参考。载入一对下路是手动参考，会替换这两个位置并保留其他位置。
   三人套路逐套整理实际位置、分工、步骤、行动窗口和短板；额外位置按分工补充，不把所有排列当作已整理组合。
   玩法来源包含 Riot 技能资料、Reddit、MOBAFire 与 BOTDIFF，可按来源及是否包含玩法配置筛选，并展开查看社区原文。人工建议未经过国服匹配胜率或版本强度验证。基础资料更新不自动验证组合库。
8. 客户端没有明确分配位置时由你安排。手动位置保留，不猜测隐藏英雄或玩家信息。
9. “清空英雄”保留你们的位置归属、英雄池和公开禁选约束；归属可用单独按钮重置。
   搜索英雄会展示非常规位置的准确匹配。条件无解时保留说明与调整入口。

出装与符文
对应版本、英雄与位置的 OP.GG 全球排位常用配置用作匹配参考，不代表国服匹配胜率。
核心方案可切换；版本、获取时间和来源在配置下方显示。
当前缓存 276 套位置配置、552 套来源完整符文，另有 40 类玩法路线及机制符文备选。
从组合库或组合推荐打开配置时，自动带上适用的组合玩法；配置里可看补刀分工和搭档方案。
“配置玩法”可切回常规位置配置，或选择 AP、穿甲、保护等适用于这个英雄和位置的路线。
“推荐符文”可选择不同完整方案，标注用途、统计来源或人工整理；选中的方案用于复制和应用。
收藏及本局指引保留所选玩法和符文；源方案失效会提示重新核对，不把旧攻略装备当成当前最优。没有对应资料时使用机制基础方案。
开启更新偏好后，打开超过 24 小时的配置会尝试刷新，失败或断网仍使用本地资料。
人工搭配与机制提示单独维护；旧规则会标明待复核，基础资料更新不等于规则已重新验证。
自动升级装备会显示应购买的前置装备。鞋子可按对线提前购买，后续装备按实际局势调整。
点击“应用到客户端”才会写符文，只新建或更新助手自己的符文页。
不会删除或覆盖其他符文页。符文页已满需自行腾出一页；游戏进行中不会写入符文。

本局指引
在英雄配置点击“本局指引”。右上角会优先带入你已选英雄的本次准备；客户端明确当前英雄时，托盘入口也会核对英雄。
浏览搭档再回来会保留所选玩法、符文和局势；已打开的同英雄同位置指引会同步配置调整。
指引窗右上角“●”可收起为悬浮球（显示下一件装备），拖动可移动位置，单击展开回大/小窗口。
指引窗顶部状态行在局内会显示“换血倾向”和即将击杀的斩杀线参考；均为按公开数据的数值参考，不代表一定胜负。
有实时面板时按真实攻防血量计算，对方这波能秒你时会单独提示；敌方伤害一边倒且路线下一步还远时，会建议一件当前金币买得起的防御装。
查看队友配置时，应用按钮写明会把该英雄符文用于你自己的客户端，请核对后点击。
小窗默认紧凑显示回城购买参考、加点与本人配合。展开可查完整路线、符文和配合步骤。
小窗独立置顶，可拖动、调整大小和不透明度，位置会保存并适应显示器变化。游戏中默认鼠标穿透，Ctrl + Shift + H 进入交互后可拖动或点按钮。快捷键未注册时保持可交互，避免无法操作。
“完整配置”返回当前英雄。刷新保留阅读位置，关闭主窗口后小窗仍可工作。
本机局内接口可用且当前英雄、地图与指引相符时，识别自己的装备、金币及技能等级。
费用按本地配方扣除已有组件，同一组件不会重复抵扣两件成装。
这是静态配方估算：海克斯折扣、任务奖励、特殊升级和热更新价格以游戏商店为准。
国服可能不提供局内接口，中断时明确提示并保留手动标记，不伪造背包或金币。
设置中可关闭局内读取。自动识别的成装只在内存中使用，卖出后更新。
本局手动标记会保存。明确的新选人 / 新局标识或局内时间重启会清空旧进度；接口不明确时仍可点“新一局”手动清理。
更换英雄、位置或模式会清空购买标记；调整同英雄的路线和局势时保留仍在路线中的标记。
回城参考会结合现有组件和金币给出一个可买配方步骤；可另选鞋子或应对装备作为本次目标，原路线保留。
同步中以真实背包为准，手动计划不算已持有；接口恢复后仍保留本局手动计划，失去同步时继续参考。
炽天使、魔切和末日寒冬等升级成品也会识别为已持有，任务升级条件以游戏为准。
配合速记支持手动切换阶段；自动阶段仅参考自己的等级和时间，不判断队友技能就绪情况。
设置可选择进游戏自动呼出，以及结束后隐藏、收起或保留。主动隐藏后同局重连不重复弹出。
已读取的本局正式位置会保留到游戏阶段；拖动分析位置不会改变客户端正式位置。
队友阵容不明确时，已准备的组合作为未确认参考显示；明确换搭档后重新选择适用方案。
小窗可直接勾选观察到的局势，不需要切回主界面；数据过期、英雄变化和模式不符分别提示。
小窗适合无边框 / 窗口模式；独占全屏可能看不到，需自行调整显示模式或用 Alt+Tab 查阅。
助手不读取游戏内存、不注入游戏、不自动释放技能、购物或控制游戏输入。

海克斯大乱斗
资料对应海克斯大乱斗（KIWI / ARAM Mayhem），不套用竞技场同名强化。
明确的队列编号可区分模式；普通 ARAM 或地图编号本身不能证明是海克斯。
先选英雄，查看该模式出装和强化参考。海克斯配置不应用常规峡谷符文。
强化可按名称、效果、稀有度和效果分类搜索。
“我的强化备选”：想尝试的灵感清单，最多 5 项，可收藏。
“本局已选”：你手动确认实际选过的强化，最多 6 项。
“本次比较”：打开实际出现的强化详情，加入比较，最多 3 项。
比较解释常见机制、触发条件、与已选强化的联系及代价，不生成强化胜率排名。
点击“我选了这项”后标记本局已选并清空本次选项。选错可点击已选标签移除。
比较与已选信息可随当前英雄的海克斯配置带入小窗。
标记“适用技能”或“动态数值”的说明不能完整展开，以游戏里当前说明为准。
可出现的强化受英雄、已选强化和热更新影响，备选不是必定出现的强化。

客户端连接
登录国服客户端大厅后点击连接。国服读取公开选人信息可能需要 Windows 管理员确认。
连接按钮通过 Windows 原生启动器申请授权，不依赖 PowerShell。连接进程使用未修改的、由 OpenJS Foundation 签名的 Node.js，系统提示须由你手动确认。
连接时显示启动进度；45 秒内未完成会恢复按钮并说明原因，可重新连接。取消授权也可重试。
若授权窗口仍未出现，可从托盘退出助手，再右键桌面快捷方式以管理员身份运行。
设置中可选择游戏目录或关闭自动同步；断开连接也能手动选人和查看全部本地资料。
LCU 与局内接口只连接本机回环地址，不记录连接密码，不保存其他玩家标识。
接口可能随版本变化。未提供明确模式时手动选择配置，不能把猜测当作已确认。

收藏、备份与更新
收藏、英雄池、排除英雄及偏好只保存在本机，无账号、上传、战绩记录或订阅。
设置中可导出 JSON 备份；导入合并收藏与排除列表，恢复备份含有的偏好和英雄池。
旧备份没有新增偏好时保留本机值。导入不替换本机游戏目录、当前阵容或符文页归属。
已内置英雄、符文、装备、组件图片及海克斯资料，断网仍可查阅。
启动时每天检查基础资料，新图片尽量缓存到本机。更新失败沿用原资料与收藏。
资料编号与游戏显示编号可能不同，国服实际版本以客户端为准。

组合库独立更新（v0.6）
1. 在“数据与连接”或组合库底部打开管理。导入 JSON 数据包会先检查并预览新增、调整和移出的内容。
2. 点击应用后，推荐、出装符文和本局指引立即使用同一套库；更新前的库保留供回退，自定义组合和收藏保留。
3. 暂未配置公共在线发布源；可填写自己有权使用的 HTTPS JSON 地址，手动检查并预览。软件不会自动应用在线数据，也不上传内容。
4. “新建自定义组合”支持下路双人与三人套路；按英雄、位置选择现有玩法配置，填写步骤和短板。
   自定义的同英雄同位置组合优先于内置版本。更新和回退不覆盖自定义内容；可导出完整库备份。
5. “编辑数据包”用于维护额外来源、专用出装和完整符文页，检查通过后再应用。装备、符文、重复英雄或位置错误时拒绝写入。
6. 每套组合显示整理版本与复核日期。基础资料变化后标记待复核；配置失效时回到常规配置并说明原因。国服实际版本以客户端为准。
7. 选人页可设置操作难度、主要玩法、是否接受近战下路和非常规位置，各位置也有独立英雄池；和全局池同时限制时取交集。
8. 方案详情里的“换这个英雄”只替换本次推荐的位置，保留其余英雄，并说明原套路是否失效。
9. 选人同步变化时，已打开的玩法卡保留供阅读并提示过期，不能载入旧方案。


v0.7 开黑组合改进
- 三人执行卡 50 套，全部十种三位置分工都有参考；下路 155 套，专用配置 40 种。
- 每位英雄按自己参与的组合打开配置。下路双人也响应抓人、保护、消耗等偏好。
- 局势条件会实际调整装备并说明替换；辅助任务装备与出门购买分开显示。
- 选人预选与锁定状态、读取时间、正式位置差异有提示；推荐按钮在顶部随时可用。
- 不填更新地址也能检查内置库与 Riot 公开版本。组合内容仍需要人工复核，支持导入预览、回退与自定义保留。
- 维护细则见《组合库维护说明.txt》。

v0.9 流程改进
- 准备摘要集中展示英雄、位置、玩法、核心路线和符文状态；符文仍须本人点击应用。
- 换搭档、导入偏好与公开选人变化会使旧方案失效；相同组合的配置选择可恢复。
- 基础资料、当前出装及组合规则分别显示状态；国服版本未核实时明确提示。
- 数据包预览按最终生效内容计算，说明个人内容保留；修改文字不自动把旧版本套路标为已复核。
- 旧备份缺少新增设置时保留本机值；自定义条目修改一项会保留其他来源、标签和整理版本。
